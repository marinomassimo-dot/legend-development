# HUMAN ACTION — Genoa contact, TX-001 denominator

**Why them.** `PMID 35573960` (Riva, … Zara, Iacomino; *Front Pediatr* 2022;10:847549,
[DOI](https://doi.org/10.3389/fped.2022.847549)), read in full here, documents that the group
**holds WOREE patient fibroblasts and already runs RT-PCR on WWOX transcripts**: *"The RT-PCR
derived from fibroblast extracts of patient and unaffected parents and age-matched neurotypical
control…"* They are the only group this repository can document as having **both the cells and the
assay**.

**Minimal assay.** Junction RT-PCR across the affected splice junction — forward primer in exon 8,
reverse in exon 9, spanning the junction — against an **exon 4–6 "core" normaliser**, run **± an NMD
inhibitor (cycloheximide)**, each arm with a vehicle twin. **Sanger-sequence every band** (a band
size is not an identity). Quantify by capillary electrophoresis or densitometry, plus junction/core
qPCR. Minimum **n = 3 independent RNA extractions** per line per condition; **blind the
quantification**. A published assay of exactly this shape exists to redesign from — Schirmer 2016,
`PMID 26857392` — so no new method is needed. Escalate to long-read cDNA only if multiple species
appear. ⚠️ **Intron 8 retention is not detectable with this primer pair** (intron 8 is 778,856 bp)
and needs a separate intron-anchored reaction.

**Material needed.** Patient-derived fibroblasts (or LCL) carrying a canonical WWOX splice-acceptor
allele, plus **two unrelated healthy control lines** and a positive NMD control transcript.

**What it measures.** Normal transcript · aberrant transcript · **aberrant:normal ratio** · residual
correctly spliced transcript · the NMD contribution (the ratio's shift on cycloheximide).

**What would change for TX-001.** The strategy's efficacy endpoint is the fraction of correctly
spliced transcript, and **no aberrant:normal ratio exists for any WWOX allele, in any tissue,
anywhere in the literature** — so TX-001 currently has an endpoint with no baseline. This assay
supplies it, and can **retire the strategy cheaply**: if correct splicing is already near-normal
there is little to recover, before any ASO design cost. **No ASO or splice-correction arm exists in
the WWOX literature at all**, so there is no in-gene precedent to borrow confidence from.

⚠️ **Nothing here assumes cells are available today.** This repository documents *feasibility* and
this group's *published* capability, not current availability or willingness. Not medical advice; no
clinical action is proposed.
