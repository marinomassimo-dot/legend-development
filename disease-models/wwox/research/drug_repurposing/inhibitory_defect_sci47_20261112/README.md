## The answer first
1. **No recording in the paper separates input number, GABA per event, postsynaptic response, chloride gradient or network state.** The inhibitory data are spontaneous events only, from a 140 mM KCl pipette (E_Cl about 0 mV, own arithmetic), at -70 mV, with no antagonist, no TTX miniature, no evoked IPSC, no paired-pulse, no E_GABA (strings searched in the full text and supplement: zero hits for bicuculline, gabazine, picrotoxin, SR95531, DNQX/CNQX/NBQX/AP5, mIPSC, perforated, gramicidin, paired-pulse, E_GABA). Matrix O01-O06.
2. **The suspected inversion is not an inversion; it is a wording hazard.** Source: sIPSC amplitude 57.3 → 27.5 pA (−52.0%), frequency 10.3 → 8.4 Hz (−18.4%; printed means, own arithmetic). Frequency falls **by** about a fifth, not **to** a fifth; amplitude falls more. No place in the repository states the reverse. What the source does **not** support is the step built on the order ("amplitude falls more, so the receptor response or the GABA content per event"): the frequency change has only a Kolmogorov–Smirnov test on pooled events (unit undeclared; the p-values lie below the floors of one value per cell), amplitude and detected frequency are not independent (a 4×SD detection threshold), a loss of a high-amplitude input class lowers mean amplitude without any change per synapse, and the event identity is not shown (no antagonist; KCl pipette at -70 mV). `output/inversion_check.md` (table of places; the verifier extended it, see consumer_delta).
3. **Which comparison stays interpretable.** Only one read on the burst endpoint with the defect measured in the same slices, against a matched non-GABAergic arm, and the genotype-by-drug interaction on the defect measure. A GABA-supply arm (L1) or a postsynaptic-modulation arm (L2) is interpretable only after mIPSC, agonist response and E_GABA place the deficit. NMDAR dependence (L4, d-APV abolished bursts in 5 slices from 3 animals) is the generic comparator, not a correction. A K+/Ih arm (L5, tied to the measured passive correlates: input resistance +39%, rest 5.6 mV depolarised, larger sag and rebound) is conditional. Chloride transport (L3) stays a **measurement** (E_GABA) that gates L1 and L2; gap junction (L6) is dropped. Occlusion of two levers is exploratory only. `output/levers.tsv`, `output/design_review.md`.
4. **Minimum design.** Phase 0, drug-free, animals as the unit, Cre-positive WT/HT/KO, layer II/III pyramidal cells P13-17: sIPSC with antagonist-defined identity and a physiological-chloride pipette; mIPSC in TTX; evoked IPSC with paired-pulse; agonist response; perforated-patch E_GABA against rest, threshold and input conductance; Rs/Cm/Rin; bursting versus non-bursting KO slices. After the verifier: not one protocol in every cell: a perforated-patch cohort (native-chloride sIPSC, mIPSC, evoked IPSC, puffed agonist) and a whole-cell high-chloride cohort, nested in the same animals. Phase 1 only for the lever Phase 0 selects. It does not extend to a new animal study.
