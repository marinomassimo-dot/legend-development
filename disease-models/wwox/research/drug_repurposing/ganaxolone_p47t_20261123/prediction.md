# Does an independent partial-loss model express the myelin-challenge program?

Freeze before examining target-gene values in GSE215425. Known: the published adult Wwox P47T model has neuroinflammation and cerebellar pathology; metadata, sample names, region-specific sample sizes and the earlier GSE171280 challenge and neuronal-null results were inspected. No P47T panel scores were opened. P47T is partial loss and SCAR12-like, not equivalent to severe early null disease. The same mice contribute multiple regions.

Primary: apply the existing 25 up and 25 down myelin-challenge genes to hippocampus, using mean log2(1 + CPM) of up minus down in each library. Aggregate by gene symbol, check raw library identity against the GEO series matrix. Require >=15 genes in each arm, display exact omissions. Compute within-sex P47T-minus-WT contrasts and give the two sexes equal weight. Report the crude and leave-one-animal-out contrasts if both genotypes remain within both sexes. Report PFC, parietal cortex and cerebellum separately as context. A generic microglial marker panel (Aif1, C1qa, C1qb, Tyrobp) is descriptive.

Alternative: the score can be driven by the cell mixture of bulk tissue. For each signature gene, use seven baseline profiles from the independently sorted mouse cortex GSE52564 (two preparations per cell class). Fix nearest neighbors by Euclidean distance on log2(1 + FPKM) standardized across the common gene universe separately in each class. Exclude all signature genes and the four markers from the neighbor pool. Use the closest 20 distinct candidates per target. Match on reference expression profiles only, independently of P47T labels or effects. For 2,000 draws with seed 20261123, sample one control without replacement per target, randomizing the target order. Repeat the tissue contrasts on these gene panels. Report both the full signature and the subset represented in both references, plus neighbor distances and effect distributions. If fewer than 15 genes per arm are represented in both sources, treat the adjusted test as uninformative.

Prioritize a transported **bulk** signal only if the hippocampal contrast is positive in both sexes, stays positive with each one-animal omission, and exceeds the 95th percentile of the matched reference effects. A positive obtained only after restricting the gene set does not overturn a failed full-panel criterion. Matched panels constitute a biological specificity benchmark, not sampling confidence or a test of causality. They cannot establish microglial debris, cell number, clearance, or ganaxolone response. Regional and sex-dependent patterns may motivate a narrower question, not a post hoc pass.
