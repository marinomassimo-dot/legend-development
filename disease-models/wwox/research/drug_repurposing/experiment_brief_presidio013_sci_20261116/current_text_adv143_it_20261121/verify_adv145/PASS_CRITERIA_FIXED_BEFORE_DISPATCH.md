# ADV-145 pass criteria, fixed by ADV and written down by IT before the reader was dispatched (2026-11-21)

Reader: a new cold reader (not the RP-041 producer or second reader), sonnet, effort high, given ONLY the new current text (with its status box and History); not QCHECK, not CHANGE_LOG, not the old texts A and B. IT compares only after it returns.

PASS if all four hold:
1. Every question the reader cannot answer maps to a marker already in the text (OPEN-GAP, CONFLICT-OPEN, laboratory or operator marker) or to an answered QCHECK cell. An UNMARKED gap is a finding.
2. No NEW conflict between sections introduced by the fold-in (a conflict the text itself marks CONFLICT-OPEN is not new).
3. The reader states unaided which text governs and where the old dated lines went.
4. The number of questions the reader still calls blocking is reported against the first read's 27 (no pass threshold is set on the number; it is a measurement).

Repair rule: edit the text only if an unmarked gap or a new conflict is found, as a dated repair, old text kept.
