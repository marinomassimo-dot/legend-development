# INV-09 GSK3: separating possible benefit from other actions (label gk-p, receipts suffix 99), 2026-11-07

Non-canonical research, not medical advice, no dose. Reference genotype class only. The external report was not used as evidence. Tables: `evidence.tsv` (E01-E31 new, R01-R06 reused), `separation.tsv`, `probes.tsv`, `experiment.tsv`, `queries.tsv`, `receipts/` (6 staged, suffix 99, validated, not recorded).

## Answer first
No GSK3 strategy is nominated; the IT15 abstention stands. What is new is a defined place where a separation could be tested: the GSK3-PI4KIIalpha branch that sets the size of the synaptic NMDA-receptor current, which can be compared with plain NMDAR block. It is a tool question, not a candidate, and it does not depend on GSK3 being over-active in WWOX deficiency.

## Decisive corrections (premises A to D)
- DATO. S9A is not a drug-resistant allele. The knock-in paper gave an ATP-site inhibitor to S21A/S9A muscle and glycogen synthase still rose about five-fold (E05); the methylphenidate paper (23099259) gives no inhibitor or lithium to any knock-in mouse (E02). INFERENZA: S9A tests loss of Ser9 control, not attribution of a drug effect. Attribution needs, per compound, an isogenic knock-out check like the one done for BRD0705 (E24), or convergent pharmacology.
- DATO. CT99021 is not isoform-selective in what was read: the Bain panel has GSK3 beta only (E28), and in cells CT99021 behaved as a dual inhibitor (E22). The biochemical 8- to 14-fold window of the matched pair shrank to 4- to 6-fold in live cells and eroded at higher concentration (E20, E21, E23): biochemical selectivity does not carry to cells.
- DATO. 32463939 attributes its effect to GSK3 beta on CT99021 alone, with no isoform test (E16); the S9/51A mutant is of PI4KIIalpha, not GSK3 Ser9 (E14); its plasmids rest on an earlier paper (E15). 33197065 (abstract only) finds alpha, not beta, required for LTD (E09).
- DATO (reused). The Wwox-null Ser9 blot is a single-lane proxy, lithium acts in wild type too, and a fixed-dose score is not a threshold (R01, R02). The neuronal model is Synapsin I-Cre; Nestin-Cre, Olig2-Cre and GFAP-Cre are other arms; no Nex-Cre appears for the Wwox model; Syn1-Cre excision is partial (R03, R04).

## The PI4KIIalpha branch (item 4)
DATO: in rat organotypic CA1 neurons (paired cells, not animals) knock-down halves the isolated synaptic NMDAR current and leaves AMPA current unchanged (E10, E11); CT99021 lowers the NMDAR current to 57 percent and is without effect after knock-down (E12, E13); a shRNA-resistant wild type rescues, S9/51A does not (E14); LTD survives (E18). INFERENZA: in this system GSK3 inhibition reduces NMDAR current, a possible route to fewer NMDAR-dependent bursts and equally a possible cost to basal transmission (LTP, development untested). Occlusion fits a common pathway but not a floor effect, since 41 pA and a Ro25-6981 response remained. It adds to the direct block of the NMDA package one thing only: a route to a partial, activity-dependent reduction, if it differs from d-APV at matched current. There is no pharmacological probe for the branch; the PI4K2A shRNA with resistant constructs is genetic. IPOTESI.

## Separation hypotheses that remain plausible (IPOTESI)
Isoform-selective inhibition can dissociate kinase inhibition from beta-catenin rise (HEK293T, leukemia lines; E22, E23; context dependent, no neural cell). Alpha and beta serve different synaptic or behavioural functions (E03, E09). Ser9/Ser21 control is separate from Wnt control (E06). The oligodendroglial sign is divided (R05, R06). None is tested in a WWOX system. Lithium is a reference, not proof of GSK3 dependence (E04, E30, R02).

## The discriminating comparison and the decision it changes
X2 in `experiment.tsv`: acute, in bursting S-KO slices, vehicle, lithium, CT99021, the BRD0705/BRD3731 pair with inactive BRD5648, and d-APV at the same measured NMDAR reduction (shared with the NMDA package); burst endpoint, isolated NMDAR and AMPA currents, per-isoform Tyr279/Tyr216 and a substrate read, viability. Then X3 (PI4K2A knock-down, resistant wild type, S9/51A) and X4 (isoform-depleted neurons). Hypothesis: if the branch sustains bursts, GSK3-route compounds reduce bursts along the same curve as NMDAR current, occluded by knock-down and rescued by wild type only, with AMPA spared. Refuted by: no occlusion, equal effect on a wild-type control at the same current, lithium effect surviving isoform depletion. Decision: carry a GSK3/PI4KIIalpha lever as a second NMDAR route, or stop. Priority remains X1: does substrate phosphorylation differ in WWOX-deficient neurons at all? Prolonged exposure (X5) is a separate arm; restored WWOX is a biological control only. In silico, not run here: PI4KIIalpha residue conservation, deposit transcripts.
