# Design rules for any materials comparison (a template; IT, 2026-11-19; from the two cases run on 2026-11-19)

Non-canonical working note. The two comparisons of 2026-11-19 (PPxY, SCI's frozen criteria; the one-slot decision, `PREREG_SECOND_COMPARISON_IT59.md`, sha256 `525c9266378bd42f6fbfde5b0d9f9e84d89c1d9a8ef2304f9fc07dbd8987ae6f`) were each confounded by something the design allowed; these rules are written so that the next one is not. A rule is added only because a defect happened; ADV's wording of the first four, 2026-11-19. Not applied retroactively: the hashed pre-registrations are not edited.

1. **Complete originals list in BOTH arms.** The list of held originals is built from the sources the materials rest on (every paper cited by the notes in the pack), not from a 'Source' column of a summary page; both arms receive the identical list. (Defect: the one-slot test gave both arms only the Brain 2021 paper, not the other originals the glucose note rests on; arm M had those facts through the note, arm L did not.)
2. **One fixed minimum PubMed (or web) step for both arms**, stated in the brief with a minimum number of queries and the question each must answer (for example: 'find and open at least one primary source per measurement not in the originals list'); an arm that skips it reports why. (Defect: arm L made 2 tool calls and searched nothing.)
3. **No pointer to an ordered page, to the answer or to a note that orders the candidates, in the lean arm's pack, and none in the structured arm's pack either unless the pointer is the thing under test.** Before dispatch the pack's files are searched by name and by string for the page's filename and the words of its ordering (a check recorded in the run record). (Defect: IT's own dated pointers to the ordering page were inside arm M's material.)
4. **Caps enforced, not requested:** word limit, tool-call limit and output format checked by the runner after each run; a report above the cap is trimmed by a rule fixed in advance (first N words) or the run is declared out of protocol, never silently accepted. (Defect: all three reports exceeded their 800-word caps: 950, 1,199 and 1,156.)
5. **Run only if a decision is scheduled that the answer would change** (ADV). A clean rerun of an earlier case is justified only then; otherwise the earlier result stands as stated with its confound.
6. Unchanged from the first pre-registration: the primary outcome is a blind verifier's category judgement, not a count; HARM and NO DIFFERENCE are defined before the runs; model, effort and inherited context are read back for both arms and the comparison is called unbalanced if they differ; effective isolation is declared (inherited instructions and memory index; the lean arm is not memory-free); cost is read from the census and reported alongside; one case, no general claim.
