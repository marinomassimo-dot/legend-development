## Readings fixed in advance (my priors)
* **R1, pair not worth reusing (0.6).** Every field that makes HC-07 recognisable is a field the four components need (drug class for C1 and C2, disease for C3 and C4, age for C4, endpoint for relevance), so no masking can remove recognisability without removing the evidence; a null identifier effect would then be uninformative.
* **R2, choice scoring trivial on this card (0.7).** The row already states the add-on design, the age range and the endpoint of the one held trial, so the choice of 'next comparison' is pre-selected by the row, and an always-pick-the-restatement baseline scores as well as any engine.
* **R3, choice scoring has a usable core (0.2).** A deterministic endpoint-fidelity rule can still be kept as a conformance check, not as a quality measure.

## Frozen choice set (five options; the output must name exactly one code)
* **K1** Randomised add-on versus placebo (or baseline), same genotype class and age range as the row, same endpoint as the row (the simple comparator).
* **K2** Same drug and population, head-to-head against another active agent, same endpoint.
* **K3** Same drug, comparator and population, a different endpoint class from the row, with no stated validated bridge to the row's endpoint.
* **K4** Same drug, comparator and endpoint, a different population (other genotype class or other age range).
* **K5** Abstain: say that the evidence supplied does not support naming a next comparison, and name the missing evidence in one sentence.

## Frozen scoring rule (reads the CODE only; the rationale text is never read by the rule)
The held result for HC-07 is ONE performed comparison, defined by three fields: comparator type (randomised placebo add-on), population (same class, ages 2 to 21), endpoint class (28-day major motor seizure frequency). Score of a choice: **MATCH** if all three fields equal the held comparison (K1 only); **MISMATCH(field)** if one or more differ (K2: comparator; K3: endpoint; K4: population), naming the first differing field in the order comparator, population, endpoint; **ABSTAIN** for K5, reported as its own count and never as a zero or a one. No mean is computed across the three states. A choice that is a MISMATCH is scored not wrong about the world but not the comparison that was performed: the key holds no result for it.
A null baseline that always outputs K1 is run through the same rule on every card; if it scores MATCH on a card, that card is read as SATURATED for choice scoring (it cannot separate any engine from the null) and is not used to compare engines.
