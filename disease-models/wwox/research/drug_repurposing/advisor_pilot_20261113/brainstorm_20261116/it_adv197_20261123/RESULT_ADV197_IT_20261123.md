## 3. Frozen choice set and rule, and the hand dry run
Frozen in the pre-registration: K1 simple comparator (randomised add-on versus placebo, same class, same ages, same endpoint), K2 head-to-head, K3 different endpoint class without a stated bridge, K4 different population, K5 abstain. The rule reads the code only: MATCH (K1), MISMATCH named by first differing field (K2 comparator, K4 population, K3 endpoint), ABSTAIN counted apart; a null baseline that always picks K1 is run on the same card, and a card where the null matches is SATURATED.
| Toy output | Code | Rationale as written | Rule result (expected in the pre-registration) | Observed |
|---|---|---|---|---|
| A | K1 | one line | MATCH | MATCH |

| D | K5, one sentence naming the missing evidence | one line | ABSTAIN, counted apart | ABSTAIN |
* **Rationale independence holds by construction:** swapping the two rationales (a fluent one on A, a one-liner on B) leaves every rule result unchanged, because the rule never reads them. That is a property of the rule, not evidence that the rationales are equally good.
* **What the rule can and cannot score.** It separates A from B only because the row states the endpoint, ages and add-on design, so K1 is a restatement of the row and K3 contradicts it. Toy C scores MATCH with no scientific content, so on this card the choice score cannot rank an engine above the null. The key holds ONE performed comparison and its result (positive on the motor-seizure endpoint); it holds nothing for K2, K3 or K4 (never performed), so those are 'not the performed comparison', not 'worse'. A plausible choice that cannot discriminate between hypotheses (the assignment's second toy) cannot be told from a discriminating one by this key: the key records that a drug worked on an endpoint, not which of two hypotheses the experiment would have separated. Toy B is penalised only for changing the endpoint, which is what the rule was written to test and nothing more.

## 4. Disposition and what a real claim needs
**REUSE PART:** the endpoint-fidelity rule as a conformance gate (a proposed comparison must state its comparator, population and endpoint and be checkable against the row), with the null baseline run beside it. **STOP:** the identifier pair and choice scoring on ADV-091 cards (concrete stopper above). One change to the sheet is free and worth making if the sheet is ever reused: delete the printed date-cut and the section 3 derivation sentence.
**What a claim that the engine chooses more useful next comparisons would need instead, so nobody reads this as that claim:** (i) an independent observed result: a source in which two or more comparisons were actually performed and the held results differ in what they discriminate (for example one that separates two hypotheses and one that does not), so the key can say which choice was the more informative, with the choices frozen before the source is opened and the null baseline run on the same source; or (ii) a prospective hold: choices frozen and hashed before any comparison is run, scored against what is later observed by someone else. A retrospective card with one performed comparison supports neither.
**One transferable lesson (existing records, ordinary edit):** when an evaluation row restates the design of the held result, the choice is pre-selected by the row; check that the null baseline fails before using a card to compare engines.
