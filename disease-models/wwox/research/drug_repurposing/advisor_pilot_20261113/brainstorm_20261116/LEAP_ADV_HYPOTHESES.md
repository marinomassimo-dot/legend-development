# LEAP ROUND: ADV hypotheses (perspective: cross-disease, metabolic and glial; non-canonical; LEAP unless stated; not medical advice)

Written alone at 08:3xZ before reading any other author's file; frozen by the commit of this file. Mechanism and class level only: no dose, no recommendation to use any agent; every class named is a label for a mechanism, BLOCK-1 not applied. All statements below are INFERENZA from general knowledge plus what the repository holds; none has been checked against a source by me, which is why each carries a held-data pre-test to be run by someone else and the first line of the judge's criteria (novelty) is open.

H-ADV-1. Perspective: WWOX as a scaffold, what its binding partners imply. Statement: WWOX loss weakens ErbB4 signalling in PV+ interneurons (WWOX is reported to bind the ErbB4 intracellular domain through its WW domains; ErbB4 in PV+ cells sets their inhibitory output), so the PV-axis findings (Aldaz 2019 PV+ loss, reduced inhibitory events, PV marker loss) share ONE upstream cause, and the five-way matrix tie on the GABA axis would collapse onto it. Rejecting observation: ErbB4 or its target genes are not reduced in PV-class pools of Wwox-deficient tissue, or neuregulin/ErbB4 pathway activation does not change the burst rate in null slices. Why a leap: the usual reading treats the inhibition deficit as a downstream consequence; this makes it a signalling deficit with a pathway handle. Test: held cell-class tables (isr_cellclass_he50 and the single-nucleus pair GSE158684: Erbb4, Nrg1, Pvalb counts in KO versus control); both outcomes change the GABA-axis rows (T2, T14, T15) from three origins to one. Class label: neuregulin/ErbB4 pathway modulators (none is an antiseizure agent; the point is the target, not a candidate). Held-data pre-test: not run by me. Would change my mind: Erbb4 unchanged in the held pools. Cost: held-table lookups.
H-ADV-2. Perspective: metabolic route (WWOX is a metabolic regulator; the ketogenic diet is a clinical class in INV-10). Statement: the Wwox-null burst depends on the energy substrate: lowering glucose or adding a ketone body changes the burst rate in null slices and not in wild type, through KATP-type conductances in interneurons or the lactate/ketone route, which would make 'diet' and 'metabolic' classes mechanistically testable in the same assay as the AED arms. Rejecting observation: no genotype-by-substrate interaction on burst rate. Test: the SCI brief's slice assay with one extra arm (substrate change) in both genotypes; outcomes: interaction present -> a metabolic row (T10) gets a genotype contrast (tier 3) and the diet class moves; absent -> the diet class stays an unexplained clinical observation. Class label: ketone-body/KATP-opener mechanism (label). Pre-test: held expression of glycolysis and ketone-handling genes in the Wwox-null tables (not run). Would change my mind: no substrate effect in the pilot. Cost: one added arm, the pilot's four animals per genotype.
H-ADV-3. Perspective: glia and myelin shape excitability. Statement: Wwox loss in oligodendrocyte-lineage cells (the CTGF/OPC threads) thins the myelin of PV+ interneuron axons, which are among the most myelinated, and a conduction-timing deficit in PV axons contributes to the reduced inhibitory output; the oligodendrocyte marker fall in the knockout single-nucleus pool (Plp1 392 to 136 CPM, a held table) is the first sign. Rejecting observation: PV-axon myelin markers (MBP, Caspr) are not reduced in null tissue, or remyelination-promoting agents do not change the burst rate. Test: held single-nucleus pair (Plp1, Mbp, Mobp in KO versus control, pool descriptive only); outcomes: supported -> the myelin line (CTGF, clemastine-type threads) acquires a link to the seizure endpoint it does not have now; rejected -> the myelin line stays a development-endpoint thread. Class label: OPC-differentiation/remyelination mechanism (label). Pre-test: partly present (Plp1), pool-level and composition-confounded (the CTGF package says so). Would change my mind: Mbp unchanged after composition adjustment. Cost: held-table lookups.
H-ADV-4. Perspective: cross-disease analogy (TSC and mTOR-driven epilepsy as the nearest pharmacologically tractable cousin). Statement: the held Wwox-null expression tables carry an mTORC1-activation signature, so a share of the seizure phenotype is mTOR-driven even though WWOX is not an mTOR pathway gene by name. Rejecting observation: no hallmark mTORC1 signature in the held KO tables (GSE156243 organoids, the mouse tables), or a signature that tracks progenitor state (the composition artefact the CTGF package found). Test: gene-set scoring on held tables; outcomes: signature present and not composition-explained -> a new thread row for the matrix with a genotype contrast and a class (mTOR pathway inhibitors, label) the AED matrix does not contain; absent -> closed at no cost. Pre-test: this IS the test; the check is a table lookup. Would change my mind: composition explains it. Cost: one script on tables already held.
H-ADV-5. Perspective: reverse the question (which readout would make ANY of the matrix's classes look WWOX-specific). Statement: the matrix cannot discriminate because all arms are scored on burst suppression, a readout shared by every excitation-lowering agent; a readout that separates WWOX-specific from generic effects is the genotype difference in the RESPONSE CURVE shape (slope and plateau of burst reduction versus agent exposure), not the mean effect: a WWOX-specific mechanism predicts a left-shifted or steeper curve in null slices, a generic one a parallel shift scaled by baseline burst rate. Rejecting observation: curves are parallel after normalising to baseline rate for every arm. Test: the same brief's pilot with two exposures per arm, no extra animals beyond one added level; outcomes: shape difference in one class -> that class becomes the first WWOX-specific match with a drug-by-genotype interaction on the ratio scale (the NX1 lesson); parallel everywhere -> the burst readout cannot give specificity, and the next step is a different readout. Class label: none (a design hypothesis). Pre-test: SCI's NX1 sizing already says the absolute scale cannot separate A from B; this applies it. Would change my mind: a held curve pair showing parallel shifts. Cost: one extra exposure level per arm.
