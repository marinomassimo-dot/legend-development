## NOTES - text / legend / plot disagreements (no interpretation)
N1 Fig 1A XBD173: text 66.1% decrease, legend 68.1%; plot ~-66 (agrees with the text). Etifoxine -64.6 agrees (text and legend).
N2 Fig 1A Ro5-4864: "5-fold increase" (text) / "5-fold higher than the BL" (legend); the plotted % change from BL is ~+500, so "5-fold" is the plotted % value, not a ratio of 5x BL. Text names XBD173 as 20 uM but the tested list (1, 5, 7.5, 10, 30, 100 uM) does not contain 20 uM.
N3 Fig 2 PTZ: Results 3.2 says 7.5 uM, 40 min; legend says 20 uM, 40 min. n: text n=9 (mutants), legend n = 2-3 per experiment; plot shows WT 4, scn1Lab 9, PTZ 5, DMSO 2-3 dots. Fig 2B P=.0100 is drawn **.
N4 Text value "92.33 +- 83.72" = Fig 3A (spikes) Etifoxine (7.5 uM, 3 h); the plotted bar top is hidden by dots (max dot ~290, cap ~180 consistent). 0.002236 +- 0.002175 = Fig 3B Etifoxine; 4.545 +- 4.886 = Fig 3C Etifoxine.
N5 Fig 3 stars vs text P (text P read against the legend scale ** <.01, *** <.001, **** <.0001): A XBD173 **** vs P<.0003; A PK11195 *** vs P=.0133 (this P would be *; legend defines no *); A STP **** vs P<.0002; B STP *** vs P<.0001; C XBD173 *** vs P<.0001; C PK11195 ** vs P<.0001; C STP *** vs P<.0001. Methods 2.8 defines **** as P<.00001, legend as P<.0001.
N6 Fig 3C draws no error bars at all (legend: mean +- SD); 3A,3B draw them for some groups only (DMSO cap obscured). Text n=9 for etifoxine; the printed bursts mean 4.545 (not an integer multiple of 1/9; 50/11 fits) and STP 0.3750 (=3/8) suggest other denominators (my inference only, no n stated per group).
N7 Fig 4 panel letters differ from legend/text (legend/text: B = firing rate, C = events; figure: B = bursts, C = rate). Plotted bar tops match the printed numbers only for B = bursts (etifoxine ~98 vs 103.9; XBD173 ~316 vs 319.2; PK11195 ~197 vs 200.6; Ro5 ~287 vs 288.9) and C = rate. DMSO and 4-AP means are printed only for 4-AP spikes (410.5 +- 255.0); other DMSO/4-AP values are READ.
