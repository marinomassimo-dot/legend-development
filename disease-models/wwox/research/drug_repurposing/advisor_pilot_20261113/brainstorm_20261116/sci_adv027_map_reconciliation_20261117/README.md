## Method (three passes; what each could and could not see)
1. **Id grep.** For each row: `git grep -n -I -F -w <qid>` over tracked files, excluding the map itself, its README, the indices, ledger and generated surfaces; per hit file the date and short hash of its last commit. 7 rows had no hit file outside those exclusions.
2. **Identifier grep after the row's `last_touched`.** Row-specific identifiers (NP*, N*, INV-*, NEED-*, CH-*, PMID, GSE, E-MTAB-*) were searched the same way, keeping files whose last commit is later than the row's `last_touched`. 61 of 82 rows had no such file; the others were dominated by generated surfaces (ranking README, shareable view, receipts), which are not answers.
3. **Rare-term ranking.** For each row the seven rarest words of its question and decision text (by document frequency over the 3,260 text files changed since 2026-10-31, excluding generated surfaces) were matched against files whose last commit is later than `last_touched`; files matching at least two were ranked. Top candidates were **read at sentence level** for the rows where they looked like answers (below) and listed, not read, for the rest.
4. **Direct checks of code and documents** for the engine and document rows (EN-01, EN-02, DC-01, DC-02, DC-03).
**Class rules.** ANSWERED: the named file states the answer to the row's own question (the sentence is quoted in the table); NARROWED: a file states part of it or a sharper remainder; ACCESS_BLOCKED: the row text and the newest file state a stop (reCAPTCHA, proof-of-work, 403, not open access, no route); STILL_OPEN_UNTOUCHED: otherwise, with the greps stated. `basis` says whether the class rests on a reading by me ("verified reading": 14 rows: WO-06, WO-23, RS-R6, TS-02, EN-01, EN-02, DC-01, DC-02, DC-03, IT46-Q03, IT46-Q11, IT56-Q02, IT56-Q05, IT56-Q09), on text the map row already carries and I did not re-read ("map row already carries it", "map row + IT55 access test" and "map row text (not re-read)": 22 rows), or on the absence of a verified sentence (46 rows; the other 3 untouched rows, DC-01, DC-03 and IT46-Q03, were checked directly and found unchanged or unplaced).
