# Signature-reversal triangulation (HE, 2026-11-16): a third method, held tables only

Written for: ADV, IT and SCI. Non-canonical; mechanism classes only; no dose, no recommendation; reference genotype class only; no live query (S8 and S9 stay off). Everything LINCS-derived is not WWOX evidence, and a knockout signature is not a rescue signature (the held file's own rule).

## Answer first
**The signature method covers 4 of the 15 (v1) or 19 (v2) classes, so it cannot test the matrix. It is a non-covering result.** The shared classes with the frozen matrix F1 are 4 (sodium channel, valproate-type, carbonic-anhydrase/multi-target, steroid/ACTH): concordance 0.30 with the per-thread-sum ranking and 0.50 with the origin-collapsed one, on 5 classifiable pairs; with IT's observed ordering only 2 classes are shared (carbonic-anhydrase and steroid/ACTH), giving 1 pair: not scorable with partial counts, 0.00 on that one pair with resolved only. All are below the pre-declared bar of 10 classifiable pairs, so the result is uninformative, not negative. My frozen expectation (FREEZE_BEFORE_COMPARISON.md, commit 817ffe1c4, 10:00:44Z, not blind) was little or no agreement; the numbers fit it.
**One class stands out and it is one agent.** Valproic acid moves the WWOX-loss glycolysis/lactate module the way WWOX loss does in 4 of 4 neuron-like signatures (aligned-tail p 0.061 against the 0.503 base rate) and in 3 of 4 progenitor-like ones; the matrix puts valproate-type in its top tie. That is a tension to look at, not a refutation: one agent, one dose (10 uM), and the module is a metabolic state, not excitability.

## What was done
1. Every antiseizure agent with a row in the held LINCS-type table, by name search over its 256 families: carbamazepine, lamotrigine, valproic acid, zonisamide, dexamethasone (mapped to sodium_channel, valproate_type, carbonic_anhydrase_multitarget, steroid_acth, the last with low confidence: a glucocorticoid is not corticotropin or prednisolone) and riluzole and nimodipine (listed, no rule class). Searched and absent: ethosuximide, levetiracetam, perampanel, vigabatrin, topiramate, phenytoin, benzodiazepines, phenobarbital, cannabidiol, fenfluramine, retigabine. Per-signature scores, with cell, context, dose and time: `signature_rows.tsv` (43 rows).
2. Per class, per context: the share of signatures with opposition > 0 minus the base rate of the same context (neuron-like 0.503 over 451 signatures; progenitor-like 0.516 over 788), with both exact binomial tails: `signature_ranking.tsv`. The raw score is not used: the same agent changes sign with context (lamotrigine: -1.31 neuron-like, +1.21 progenitor-like; carbamazepine: 2 of 2 opposing neuron-like, 1 of 3 progenitor-like), so a class effect is read against its context's base rate. Strong-opposition base rates over all signatures are 17.8 percent (score above 1) and 16.5 percent (below -1), close to the 18.0 and 16.6 percent ADV quoted; I used the sign share because the counts per class are 2 to 4.
3. Frozen first (`FREEZE_BEFORE_COMPARISON.md`), then compared (`triangulate.py`, output `triangulation.tsv`) with the frozen matrix F1 scores read from SCI's freeze commit f5b71a3f4 and with IT's observed ordering re-derived from the sealed extraction by the cross-check code. Ties score 0.5; a tied reference pair is not classifiable.

## Limits
n is 2 to 4 signatures per class and one dose. The held table is a 256-family subset chosen for coverage of the six-gene module in neural LINCS contexts, so it holds none of the channel agents the matrix puts at the top (no T-type, GluN2B, benzodiazepine or GABA-AT row), and its readout is a glycolysis/lactate module. A class can be absent here for a reason that has nothing to do with WWOX. The mapping of agent to class is mine and declared in `signature_ranking.py`. IT's observed ordering and the matrix are not independent of what I had seen: the freeze says so. A wider signature query (the full L1000 for these agents) would need a live service, which this round does not use.

## What would change this
A held table with the other agents of the 19 columns, or a live query authorised later. With 10 or more classifiable pairs the comparison would become a real third method; today it is a feasibility note: signature reversal can place at most 4 classes.
