# Reproducing the ADV-147 numbers (SCI window X, 2026-11-21; not medical advice)
Third-party data are not committed. Inputs: `https://cells.ucsc.edu/cortex-dev/exprMatrix.tsv.gz` and `https://cells.ucsc.edu/cortex-dev/meta.tsv` (UCSC Cell Browser dataset `cortex-dev`, Nowakowski 2017; digests in `input_digests.sha256`). Steps: extract the WWOX and 20 control-gene rows of the matrix into `cd_rows.json` (keys `hdr`, `rows`; stdlib gzip read, gene name before any `|`), run `python3 -I analyse.py`, `python3 -I depth.py` (writes `depth.json`), then `python3 -I strat.py`. The scripts read from the job scratch folder (current directory). `analysis_out.txt` and `strat_out.txt` are the outputs of this run.
