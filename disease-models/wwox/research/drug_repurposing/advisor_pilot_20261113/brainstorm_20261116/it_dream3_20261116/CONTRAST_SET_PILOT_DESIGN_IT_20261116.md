# Contrast-set pilot: design and the status of the source method (IT; non-canonical; hypotheses; mechanism level; not medical advice)
**Source method, read first (ADV's request: licence and code).** 'Contrastive Discovery: Open-Ended Scientific Discovery over Competing Explanations' (Liu, Kim, Dai, Sun; ICML 2026 virtual page https://icml.cc/virtual/2026/67941; aggregator summaries https://deeplearn.org/arxiv/868818/contrastive-discovery:-open-ended-scientific-discovery-over-competing-explanations and https://chatpaper.com/paper/375049). According to the web search of 2026-11-16 (abstract/aggregator level only; the full paper was not read): a contrast set pairs a question with mutually exclusive and collectively exhaustive explanations; each experiment is scored by how its evidence redistributes belief across the set; reported across six domains: 73% of the highest-belief-shift rejected candidates resolved to a specific alternative; 67% more questions resolved than pointwise surprisal at equal budget; 78% agreement of 38 blinded experts on resolved questions. LICENCE: not found. CODE: not found (no repository located by the search). Status: CLAIMED IN PAPER, code not verified, no licence read; the pilot below imports nothing and needs no code.
**Design (as stated at the meeting).** Question: for I13 (tonic deficit), I1 (rebound oscillator) and I15 (threshold endpoint), does replacing SUPPORT/REFUTE by a contrast set change which experiment the engine chooses first? (1) A blind delegate (sonnet/high; one active; queued behind HE's two delegates) receives only the held observations (the 0/11, 4/23, 36/42 incidence; sIPSC 57.3 v 27.5 pA with cell counts; intrinsic profile S-HT = S-KO; the K2P/Kir/Kv7 PY scan; the GAT result; the tonic-current sizes) and, for each of the three, builds a contrast set of two or three mutually exclusive explanations of the SAME held observation. (2) A second blind reader assigns each existing result to the alternative(s) it supports or leaves untouched (cells: result x alternative: supports / opposes / silent). (3) The engine's output per hypothesis: residual alternatives after the held results and the first experiment that best separates them. The engine must beat the day's actual SUPPORT/REFUTE path in (a) the number of residual alternatives after the held results, (b) the first experiment chosen, (c) agreement of the two readers on the cells (threshold fixed before the second reader starts: at least 80 percent of cells; with 3 hypotheses nothing is claimed: the output is cost and disagreement). (4) Shared check with HE's retrodiction: would the contrast set have put the phasic deficit first before SCI's rivals scan (SCI's order of results is in RIVALS_RESULT_SCI.md; the retrodiction cut is HE's). Briefing line required in every batch (ADV item 6): Sibyl's three failure-mode questions, to be pasted when HE sends them.
**Cost estimate (before launch):** about 60k to 120k total tokens for the builder and 40k to 80k for the second reader. Zero literature; zero spend.
## Generation-brief lines required in every batch (from HE, ADV decision item 4; Sibyl temporal-backtesting audit, ICML 2026; checked against HE's test (a)); applied to this pilot and to every batch brief of IT
1. CONTAMINATION: before a hypothesis or contrast alternative is called new, grep the held tree at the batch's cut for the target's PMID, first author and the distinctive terms, and write the file count beside the claim (the author check can matter when the PMID check says 0).
2. FRAMING LEAK: for each hypothesis or alternative, state which held file or later result shaped its wording; a wording written after the answer was known is a restatement, not a prediction.
3. CITATION CHECK: every cited paper or file path in a generated hypothesis is opened once (path exists, quote is in it) before it counts.
Count, per batch, how many hypotheses fail each line, so counts compare across rounds. In this pilot the cut is the commit that adds this file's successor (the builder's brief names it); the builder reports the three counts per alternative.
