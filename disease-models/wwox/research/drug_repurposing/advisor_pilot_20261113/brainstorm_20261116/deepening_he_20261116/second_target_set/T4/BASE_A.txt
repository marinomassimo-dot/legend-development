H1. Statement: The mutant Gαo acts as a dominant negative (it traps Gβγ, GPCRs or RGS partners), so silencing the mutant allele while leaving wild-type Gαo in place restores Gαo/Gβγ signalling. · Evidence: Some variants (e.g. G203R) behave as if they sequester partners or are nucleotide-locked, and reported variants span loss-of-function, gain-of-function and "neutral" classes in cell and C. elegans assays. Allele-specific silencing has not been shown to work in Gnao1 models, so this is none known as a rescue. · Usual reading assumes the problem is too little Gαo activity, so the fix is more Gαo. This one changes that: the problem is interference by the mutant, so removing it is the fix. · Rejection: if lowering mutant protein (allele-specific knockdown in neurons or iPSC neurons) leaves GPCR→GIRK or →Cav2 coupling unchanged, H1 is rejected. · Discriminating manipulation: allele-specific knockdown of the mutant (ASO/siRNA class) versus adding wild-type Gαo (H2). Prediction: knockdown improves both motor function and seizures, and wild-type addition does not.

H2. Statement: The pathology is functional haploinsufficiency, so raising wild-type Gαo dosage above the threshold (gene supplementation or transcriptional upregulation of the normal allele) restores signalling. · Evidence: Gnao1 heterozygous knockout mice show mild motor and seizure-susceptibility phenotypes, and some patient variants appear to cause loss of function. Both are partial support only. · Usual reading assumes that every patient variant has the same mechanism, mutant-driven toxicity. This one changes that: the extra wild-type protein out-competes or replaces the mutant. · Rejection: if wild-type overexpression in a mutant neuron or mouse does not raise Gαo-dependent GIRK or Cav2 modulation, H2 is rejected. A worsened phenotype would point to dominant-negative behaviour (H1). · Discriminating manipulation: neuronal wild-type Gαo overexpression on the mutant background versus allele-specific knockdown (H1). Prediction: motor and seizures both improve if H2 is true, and neither improves if the mutant is dominant negative.

H3. Statement: The mutant is misfolded or unstable and is cleared, so enhancing the Ric-8B (GEF/chaperone) pathway or applying a chemical-chaperone or proteostasis class restores the amount of functional mutant. · Evidence: Ric-8 proteins are required for Gα folding and stability. Reduced expression of some mutants has been reported in heterologous cells. In vivo rescue is none known. · Usual reading assumes the mutant protein is present at normal levels and merely inactive. This one changes that: it is under-abundant, so rescuing abundance rescues function. · Rejection: if a mutant has normal steady-state levels and half-life, and a Ric-8B boost or chaperone raises neither level nor signalling, H3 is rejected. · Discriminating manipulation: Ric-8B (or proteostasis) upregulation versus membrane-lipidation enhancement (H4). Prediction: for a destabilised mutant, motor function and seizures both improve. For a lipidation-deficient mutant, neither improves.

H4. Statement: The mutant fails to be lipidated (N-myristoylation or palmitoylation) or to localise correctly at the plasma membrane, so shifting the palmitoylation balance restores membrane coupling. · Evidence: Several Gαo mutants mislocalise (reduced plasma-membrane, increased Golgi or cytosolic signal) in cell assays, and Gαo is palmitoylated at its N-terminus. Rescue by manipulating the lipidation cycle is none known. · Usual reading assumes the defect is intrinsic to GTP binding or hydrolysis. This one changes that: the defect is trafficking, and the nucleotide cycle is intact once the protein reaches the membrane. · Rejection: if a mutant is correctly membrane-localised and palmitoylated, and artificially raising palmitoylation (zDHHC upregulation or depalmitoylase inhibition) does not change coupling, H4 is rejected. · Discriminating manipulation: depalmitoylase-inhibitor or zDHHC-boost class versus Ric-8B (H3). Prediction: motor function improves and seizures improve only in mislocalised variants. Nothing changes in variants that localise normally.

H5. Statement: In gain-of-function variants (slow GTP hydrolysis, constitutive GTP-bound state), increasing GTPase-accelerating activity (RGS, R7-family RGS7/Gβ5 or RGS4/RGS9-2) restores normal signal termination. · Evidence: Variants at R209 and E246 show gain-of-function features in cell and worm assays, and genotype–phenotype reports link gain-of-function or neutral classes to movement disorder with less epilepsy. RGS rescue is none known. · Usual reading assumes the mutant cannot be corrected and must be removed (H1). This one changes that: it can be re-timed by a different GAP. · Rejection: if RGS overexpression does not shorten the deactivation of a mutant Gαo, because the hydrolysis block is RGS-insensitive, H5 is rejected. · Discriminating manipulation: RGS overexpression versus allele-specific knockdown (H1) on a gain-of-function variant. Prediction: motor function improves, and seizures change little because gain-of-function variants are less epileptogenic.

H6. Statement: The motor phenotype comes from Gαo loss of function in striatal cholinergic interneurons or indirect-pathway neurons, while seizures arise from cortical or hippocampal excitatory neurons, so rescuing each cell type separates the two phenotypes. · Evidence: Gαo is highly expressed in striatum and cortex, and conditional work on Gnao1 is limited. Cell-type-specific rescue is none known. · Usual reading assumes one global neuronal defect produces both phenotypes. This one changes that: there are two anatomically separable defects. · Rejection: if restoring the mutant-corrected allele in ChAT-positive neurons or in D2 medium spiny neurons fails to improve motor scores, H6 is rejected. · Discriminating manipulation: ChAT/Drd2-Cre rescue versus Emx1-Cre (pallial excitatory) rescue. Prediction: the striatal rescue improves motor function and does not reduce seizures, while the Emx1 rescue reduces seizures with little motor benefit.

H7. Statement: Paralogous Gαi/Gαz subunits can partially take over the dysfunctional Gαo role at shared GPCRs, so raising Gαi expression compensates. · Evidence: Gαo and Gαi share Gi/o receptors and effectors, and all are pertussis-toxin sensitive. Compensation in these syndromes is none known. · Usual reading assumes Gαo-specific signalling is irreplaceable. This one changes that: the downstream readout is shared and the paralog can supply it. · Rejection: if Gαi overexpression does not restore GPCR-evoked GIRK activation in mutant neurons, H7 is rejected. · Discriminating manipulation: Gαi2/Gαi1 overexpression versus wild-type Gαo supplementation (H2). Prediction: partial rescue of motor function and weaker seizure benefit, because Gαo-specific roles in the presynapse remain. It fails if a dominant-negative mutant sequesters the shared Gβγ or receptors (H1).

H8. Statement: Loss of Gαo inhibition of adenylyl cyclase raises striatal cAMP/PKA, so lowering adenylyl cyclase 5 (ADCY5) activity restores the balance. · Evidence: Gain-of-function variants in ADCY5 cause an overlapping dyskinetic phenotype, which supports the shared pathway. Rescue of a Gnao1 model by reducing ADCY5 is none known. · Usual reading assumes the Gβγ–channel arm (H9) is what matters. This one changes that: the cAMP arm of Gαo output drives the motor phenotype. · Rejection: if striatal cAMP/PKA is normal in the mutant, or Adcy5 haploinsufficiency does not change the dyskinesia, H8 is rejected. · Discriminating manipulation: Adcy5 knockdown or an AC5-inhibitor class versus GIRK/Cav modulation (H9). Prediction: motor function improves, and seizures are unchanged because the cAMP arm is mainly striatal.

H9. Statement: Loss of Gαo-released Gβγ inhibition of presynaptic Cav2 channels and of GIRK activation causes hyperexcitability, so reducing presynaptic release (Cav2.2/α2δ class) or boosting GIRK/Kir3 compensates. · Evidence: Gαo and Gβγ modulate Cav2 and GIRK, and Gnao1 knockout mice have seizures and tremor. Rescue by channel-class manipulation in patient-variant models is none known. · Usual reading assumes the fix has to be at the G protein. This one changes that: the effector arm can be corrected downstream, with the mutant still present. · Rejection: if Cav2 or GIRK currents are normal in mutant neurons, or channel modulation does not affect network hyperexcitability, H9 is rejected. · Discriminating manipulation: α2δ ligand/Cav2.2 reduction (or GIRK activation) versus Adcy5 lowering (H8). Prediction: seizures decrease, with only a partial effect on motor function.

This one changes that: it assumes a hypomorph that is receptor-limited. · Rejection: if the mutant has no measurable agonist-evoked GTP binding or downstream effector response even at saturating receptor drive, H10 is rejected. · Discriminating manipulation: Gi/o-GPCR PAM class versus Ric-8A boost.
