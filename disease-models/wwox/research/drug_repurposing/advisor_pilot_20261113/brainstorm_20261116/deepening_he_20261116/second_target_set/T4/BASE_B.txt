Frame: I take the gene to be GNAO1 (Gαo), where some variants cause epilepsy-leaning loss of function and others cause movement-disorder-leaning gain of function or mislocalised mutants. GNAL (Gαolf) and GNAI1 are the same logic. Everything below is IPOTESI from memory, at mechanism level only. Evidence lines are hedged because I did not check sources.

H1. Statement: Raising wild-type Gαo (gene addition or upregulation of the normal allele) restores function by out-competing a mutant that sequesters Gβγ, receptors or GAP/GEF partners. · Evidence: Haploinsufficient Gnao1 mice have seizure and motor phenotypes, which supports dosage sensitivity. Some mutants behave as dominant-negative in cell assays, though this is variant-dependent. Rescue by dosage in patient-allele animals is not known to me. · Usual reading vs this one: The usual reading treats the mutant as a gain of function that needs removing. This one says the mutant mainly acts by occupying shared partners, so adding wild-type is enough. · Rejection: If a mutant-expressing neuron has the same Gαo-dependent readout (GIRK current or cAMP inhibition) when wild-type Gαo is doubled as it has without the extra wild-type, the lever is rejected. · Discriminator vs H2: Add wild-type Gαo in forebrain GABAergic neurons without lowering the mutant. Predicts partial seizure rescue and little motor rescue if the dominant-negative effect is in the striatum. If the lever is true, both outcomes improve with dose-matched wild-type, and removing the mutant (H2) adds nothing beyond that.

H2. Statement: Selective lowering of the mutant allele's product (allele-specific knockdown) restores function because a toxic gain of function or dominant-negative effect is the main driver. · Evidence: Allele-specific silencing is a general strategy for dominant disorders. For GNAO1, a wild-type-sparing approach has been discussed, but I know of no outcome data. · Usual reading vs this one: The usual reading says to replace the missing function. This one says removing the mutant matters more than adding wild-type. · Rejection: If knocking down only the mutant transcript in mutant neurons leaves the Gαo signalling readout and network excitability unchanged, it is rejected. · Discriminator vs H1: Compare mutant-allele knockdown with a non-selective total Gαo knockdown in the same cell type. If H2 holds, selective knockdown rescues motor function and seizures while total knockdown worsens both. If H1 holds, total knockdown is no worse than selective knockdown. A gain-of-function mutant would be rescued for motor function and seizures by the selective approach.

H3. Statement: Accelerating GTP hydrolysis (RGS-family GAP activity, e.g. RGS17/19 class) restores function in mutants that are stuck in the GTP-bound state. · Evidence: Several patient mutants show altered nucleotide handling and reduced or locked GTP-bound behaviour in vitro. RGS modulation in vivo is unproven. · Usual reading vs this one: The usual reading assumes the mutant is inert. This one says the mutant is overactive and failing to turn off. · Rejection: If a fully hydrolysis-competent mutant (or RGS overexpression) does not normalise Gαo-dependent effector output, the lever is rejected. · Discriminator vs H4: Overexpress or delete an RGS GAP in striatal medium spiny neurons only. If H3 holds, motor function improves in mutants that are GTP-locked, and seizures are unchanged or improved only if the same mutation lowers cortical thresholds. If instead the defect is trafficking (H4), the RGS manipulation has no effect.

H4. Statement: Boosting folding, palmitoylation or membrane targeting (Ric-8-class chaperones, depalmitoylation control) restores function in mislocalised or unstable mutants. · Evidence: Some mutants show reduced membrane localisation or stability in cell models. Ric-8 chaperones are required for Gα folding. In vivo rescue is not known to me. · Usual reading vs this one: The usual reading assumes the protein is made and in place but dysfunctional. This one says it is made but sits in the wrong compartment. · Rejection: If the mutant is already at normal membrane abundance and the Gαo readout is still impaired, the lever is rejected. · Discriminator vs H3: Raise Ric-8 chaperone activity (genetic overexpression) in the affected neurons. If H4 holds, it improves both motor function and seizures for the trafficking-defective subset. If H3 holds, it has no effect or worsens output in GTP-locked mutants.

H5. Statement: Raising a Gαi paralog (Gαi1/2/3) restores inhibitory signalling by taking over the functions Gαo can no longer perform. · Evidence: Gαi and Gαo overlap in cAMP inhibition and Gβγ release. The paralogs are not equivalent for channel coupling, and in some tissues Gαo is far more abundant. Direct rescue evidence is none known. · Usual reading vs this one: The usual reading treats Gαo function as irreplaceable. This one says its inhibitory output is partly substitutable. · Rejection: If forced Gαi expression in mutant neurons does not restore GIRK or cAMP inhibition, it is rejected. · Discriminator vs H1: Overexpress a Gαi paralog in an otherwise untreated mutant neuron population. If H5 holds, it improves motor function and seizures even though no wild-type Gαo is added. If H1 holds, it is not enough.

H6. Statement: Amplifying upstream Gi/o-coupled receptors (M4 muscarinic, D2, GABA-B, α2 classes) pushes residual mutant signalling over threshold. · Evidence: M4 positive allosteric modulators and D2-pathway agents act through Gi/o in striatum. Whether a partially functional mutant can respond is untested. · Usual reading vs this one: The usual reading says the receptor-to-G-protein link is the broken step. This one says the link is attenuated but still usable. · Rejection: If agonist or allosteric potentiation produces no change in Gαo-dependent readout in mutant cells, the lever is rejected. · Discriminator vs H7: Apply an M4-class potentiator in cholinergic-receptor-expressing medium spiny neurons only. If H6 holds, motor function improves and seizures are unchanged unless the receptor is in cortex. If H7 holds, a direct effector agonist works while the receptor class does not.

H7. Statement: Bypassing Gαo by activating GIRK channels (the Gβγ output) restores neuronal inhibition. · Evidence: Gαo-linked Gβγ drives GIRK; GIRK2 loss changes seizure thresholds. GIRK activator classes exist, but benefit in a Gαo mutant is unknown. · Usual reading vs this one: The usual reading tries to repair the G-protein. This one skips it and repairs its output. · Rejection: If GIRK currents in mutant neurons are normal at baseline and their excitability is still elevated, it is rejected. · Discriminator vs H8: Overexpress GIRK2 in forebrain inhibitory interneurons. If H7 holds, seizures fall, with a smaller change in motor function. If H8 holds, GIRK activation does nothing for presynaptic release.

H8. Statement: Limiting presynaptic Cav2 (N-type and P/Q-type) calcium entry restores function, because a failed Gαo brake leaves release excessive. · Evidence: Gαo inhibits voltage-gated calcium channels via Gβγ, and N-type channel blockers exist at class level. Direct rescue in a Gαo mutant is none known. · Usual reading vs this one: The usual reading puts the problem postsynaptically in cAMP or GIRK. This one puts it in transmitter release. · Rejection: If a Cav2 blocker class does not change evoked release in mutant slices, the lever is rejected. · Discriminator vs H7: Block Cav2.2 selectively in presynaptic terminals (conditional deletion) while leaving GIRK untouched. If H8 holds, seizures and chorea-like motor signs both improve. If H7 holds, only the postsynaptic-inhibition-related component improves.

H9. Statement: Dampening the striatal indirect-pathway cAMP/PKA cascade (adenylyl cyclase 5 or PDE-class control) compensates for lost Gαo inhibition of cAMP. · Evidence: AC5 is the dominant striatal adenylyl cyclase, and AC5 loss alters motor behaviour. Gαo/Gαi inhibition of AC is well established. Rescue in a Gαo mutant is none known. · Usual reading vs this one: The usual reading says to repair the G-protein. This one says the second messenger can be set directly. · Rejection: If cAMP in mutant striatal neurons is already normal, it is rejected. · Discriminator vs H10: Delete AC5 only in D2-receptor-expressing medium spiny neurons. If H9 holds, hyperkinetic motor signs improve and seizure frequency is unchanged. If H10 holds, deleting AC5 changes nothing.

H10. Statement: Reducing acetylcholine release from striatal cholinergic interneurons (ChAT-cell manipulation, muscarinic antagonism at class level) restores motor control because mutant Gαo disinhibits them. · Evidence: Cholinergic interneurons are central to dystonia models, and anticholinergics are used in dystonia generally. Link to Gαo mutants is none known. · Usual reading vs this one: The usual reading puts the defect in medium spiny neurons. This one puts it in the cholinergic interneuron. · Rejection: If cholinergic interneuron firing and acetylcholine release in mutant slices are normal, it is rejected. · Discriminator vs H9: Silence cholinergic interneurons chemogenetically while leaving medium spiny neurons alone. If H10 holds, motor signs improve and seizures are unchanged. If H9 holds, silencing them has no motor benefit.
