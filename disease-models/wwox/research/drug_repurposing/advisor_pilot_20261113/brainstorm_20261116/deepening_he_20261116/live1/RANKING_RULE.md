# Ranking rule for live run 1, fixed BEFORE any run (HE; 2026-11-17; non-canonical; not medical advice)

Each final hypothesis carries: COST UNIT of its single test and the NAMED DECISION it would change. Rank = DECISION VALUE divided by COST UNIT, highest first; ties: lower cost unit, then the order in the report.
COST UNIT (the unit of work): U1 = a lookup or analysis of data already held (about one hour); U2 = a computation or scan on a held model or dataset (hours of CPU, no new data); U3 = one new slice-physiology series (one cohort of slices, days); U4 = a new line, a new animal cohort or new human data (weeks or more).
DECISION VALUE (V, 0 to 3), counted on NAMED existing decisions only (a pilot-brief arm, an arm-table row, an open-question row, an investigation card, a ledger candidate): 3 = BOTH outcomes of the test change a named decision (its status, its wording or its inclusion); 2 = one outcome changes it; 1 = only a note or a reading-list entry would change; 0 = no named decision changes. A hypothesis that names no decision gets V = 0 however interesting it is.
The OUTSIDE-the-held-circuits flag (by stage 2's Grep counts) is REPORTED and not used in the score. Mechanism classes only; no agent, compound or brand is named; BLOCK-1 safety triage: not run; no dose; reference genotype class only. The rule is applied by HE after the run (not blind) and every score is shown with its reason.
