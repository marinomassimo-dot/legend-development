# The next cue: one question for the 13:46Z meeting (HE; 2026-11-17; no run; non-canonical)

**Question.** What is the cue that is narrower than a table of modulators and not external to the model, if any? Evidence so far (T7, tuned-on): four of four uncued runs (the C2M step, a family-first table) never name zinc, the one run where zinc was in view keeps it with the right direction, and the model states that zinc inhibits cyclases when asked directly (probe); an external structured source (UniProt GUCY2C) and a literature-retrieval cue (64 weak PubMed records) would not have supplied it either (ADV's two single probes). So the missing step is a prompt that makes the model go through ITEMS one at a time instead of producing a list from the defect.
**Form 1, a fixed item checklist (target-independent).** A short list of items declared once, before any target, from a generic source (for example the physiological ions and metals of a standard physiology text, the standard cofactors, pH, temperature, redox couples), plus the family frame of the FF step; the tool-free delegate answers one line per item: 'is this item known to modulate any member of the defective family or its two closest relatives; direction'. Not tuned on the answer only if the list is fixed and published BEFORE any target is chosen, is the same for every target and every defect, and zinc is on it for the same reason as every other trace metal. About 20 to 30 thousand tokens per run (a 25- to 40-line answer); two runs per target about 50 to 60 thousand, plus the unchanged stage 2 (about 150 thousand) for a full test. Risk: the list is itself a lever class named in the prompt (like the v4 template), so class-level credit is void and only the specific member counts; it may add noise (every item gets an answer) and it can only help where the lever is an item of the list (ions, cofactors, conditions), not a drug or a gene.
**Form 2, a neighbour-specialist step.** The model is asked, tool-free, to answer as a specialist of the closest related family (for a receptor guanylyl cyclase: the adenylyl cyclase biochemist) 'which substances and conditions do you test on your family, and which of them would you expect to act on the neighbouring family, with the direction', and then as the defective family's specialist 'which of these has anyone shown on yours'. The T7 probe suggests the model volunteers 'Zn2+ inhibits adenylyl cyclase as a general principle' when asked about the neighbour. About 30 to 40 thousand tokens per run (two answers); two runs per target about 70 thousand. Risk: the specialist roles may reproduce the same table; it depends on which neighbour is named, and the neighbour has to be right.
**What neither form tests.** Whether a cue that is declared in advance and the same for every target is a legitimate generator step or a tuned answer: that is a rule to settle at the meeting (the list or the neighbour must be fixed before a target is chosen).
