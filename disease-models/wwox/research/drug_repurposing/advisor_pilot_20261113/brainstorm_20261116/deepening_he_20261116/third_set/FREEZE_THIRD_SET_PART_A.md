## 1 · The candidate change, v4
v4 = v3 with ONE change: stage 1 is replaced by `briefs/V4_S1_TEMPLATE.txt`, a memory-free enumeration step. The model first names the defect in physical-chemical terms and lists, for seven axes (catalytic cycle: cofactors, divalent ions, substrates, nucleotides, redox, pH; folding and stability; assembly, trafficking and localisation; substrate and metabolite supply; degradation and turnover; downstream bypass; cell type, timing and dose), every lever it would consider, without pruning; then writes 15 hypotheses so that every axis with a lever appears. Stage 2 is the unchanged v3 stage 2 (corpus-grounded, inside/outside classification, at least 3 outside kept, support / contradict / not stated, silence never contradiction). The enumeration is the only difference, so v4 versus v3 isolates it. The template names no target, no gene and no lever class beyond the generic axes. sha256 of the template: 7293bc45ac8a8bba50b9cefbc08114cd9d1c7375dc278034fa66776b8cec0759.
## 2 · Question-leak audit (standing line of the target-selection rule)
`LEAK_AUDIT_PROCEDURE.md` (sha256 7bd108e43a98e109ce8e492c03b481cf77875f544062c40f91ea95d7c26e36d7): the question names only the defect and the outcomes, never a mechanism family; a tool-free delegate shown the question only lists the lever classes it suggests; a class equal to the atom class means the question leaks and is rewritten; the audit and the rewritten question are frozen with hashes. A target whose class cannot be separated from its defect is dropped.
## 3 · Conditions and runs
C3 memory-free baseline, C4 v3, C5 v4; each TWICE with a fresh delegate (sonnet, `legend-deepdive`, one at a time, path audit from every transcript, reports hashed before any atom is opened); memory probe per target before its baseline; blind reader per target (60 hypotheses: 3 conditions x 2 runs x 10, shuffled with a NEW seed per target, key hashed first, my own first pass written before the reader answers, and written without printing arm labels). v1 is dropped from this set: set 2 showed v1 equal to v3 and the baseline on every target, v1 is not part of the v4 question, and dropping it saves about 25 percent; this is reversible by ADV before the freeze digest. The reader gets an additional question QX (enumeration credit): does the hypothesis name a lever on an axis that no other hypothesis of its run names; reported per condition as the number of distinct axes covered per run.
## 4 · Targets (Part B, to be frozen by metadata after the audit)

## 5 · Decision rule (amended by ADV A1-A4; fixed with the digest)
v4 is called better than v3 ONLY IF: on BOTH absent-axis targets, v4 reaches the STRICT atom (the specific member and direction; for a target whose atom class is named in the v4 template's axis list, lever-class credit is void for this decision and reported beside it only, see A1) in at least one replicate while v3 and the baseline reach it in none, or v4 reaches it in both replicates while v3 and the baseline reach it in at most one; AND on the control target v4 is not below the baseline or v3 (strict hits); AND QX shows v4 covering more distinct axes per run than v3 (a mechanism check, not a result). Otherwise no improvement is claimed. If neither absent-axis target is reached by any condition, the finding is that the enumeration does not propose a class the model cannot name, and the change is dropped. One set of three is small and licenses a statement about this set only.
## 6 · Predictions (committed now, before targets are known)
v4 reaches the atom of an absent-axis target in at least one replicate: 30 percent (the enumeration widens the list but the model still has to rate an unknown class plausible, and the corpus step may demote it); v3 or the baseline reach it: 10 percent each; v4 covers more distinct axes per run than v3: 85 percent; v4 not below baseline on the control: 80 percent.

## 8 · Limits
One model and one delegate type; targets chosen by me from PubMed, which is a selection bias that the probe, the corpus counts and the leak audit reduce but do not remove; the one-outcome targets are single-paper headlines; the enumeration step could raise the count of weak hypotheses (QX measures coverage, not quality); the control target does not prove the engine does not hurt elsewhere.

## 9 · Amendments by ADV (accepted, 2026-11-17)
A1 TEMPLATE-NAMED CLASS. The v4 template names classes in its axes (cofactors, divalent metal ions, nucleotides, redox, pH; chaperones, osmolytes; lipidation; export or targeting factors). For any target whose atom class is one of those terms, LEVER-CLASS credit is void for the v4-versus-v3 decision (the axis list is an input of v4, not an output); only STRICT credit decides, and class-level hits are reported beside it. The leak audit gains one line recorded at the freeze of each target: template-named class yes or no (added to `LEAK_AUDIT_PROCEDURE.md`, point 6).
A2 QY, three scoring points per target and condition, no extra run: (i) is the atom class present in the printed ENUMERATION block, (ii) in the 15 stage-1 hypotheses, (iii) in the final ten of stage 2. This separates an enumeration failure from a selection failure: class in the enumeration and dead at stage 2 means the corpus step demotes and the next change is to the stage-2 rule; class not in the enumeration means the enumeration failed.
A3 THE SET CAN MOSTLY REJECT. With the 30 percent per target stated in section 6, both absent-axis targets reached is about 9 percent under independence (0.3 x 0.3). The expected result is 'no improvement, the change is dropped'; this is written before the run so that a null is not read as a surprise.
