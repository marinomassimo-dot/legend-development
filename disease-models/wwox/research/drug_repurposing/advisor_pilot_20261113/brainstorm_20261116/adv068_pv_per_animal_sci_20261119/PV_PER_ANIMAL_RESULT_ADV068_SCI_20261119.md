# ADV-068 result: is the lower Pvalb transcript PV-specific? Per-animal bulk RNA at P17 (SCI, 2026-11-19; hypothesis level; in silico; main-session turns only, no delegate; no dose, no recommendation for or against any agent in any person; reference genotype class only; not medical advice)

Asked by ADV (census choice A, premise RP-019 "Distinguish PV population, maturation, marker expression and circuit changes"). Pre-registration frozen and committed before any count was opened: `PREREGISTRATION_FROZEN_BEFORE_ANY_COUNT_SCI_20261119.md` (sha256 d4cb22739d9913db0b3d1ec408105ee3856d90bded088d3bf91cffa61919a44c, commit c50422d0e). The analysis script was written after that commit and not changed after the first run; a second script (post hoc, labelled) was written after the primary verdict was read.

## Answer first
1. **The pre-registered stop rule fired, at its boundary.** In the primary contrast (cortex, neuron-targeted deletion, 3 knockout against 4 control animals) the reference-normalised PV gene set falls by log2 -0.65 and the late-maturing non-PV set by -0.33 (0.51 of the PV shift; the rule asks for at least -0.25 and at least half): rule **R-B, "falls together", the pre-registered STOP**. Two limits travel with it: the composition caveat is flagged (oligodendrocyte guard genes -1.02 against the -1.0 threshold), and **one gene decides it**: dropping Slc12a5 from the late set moves it to -0.235 and the verdict to R-D (mixed); dropping any other single gene keeps R-B.
2. **What the per-animal data say.** The PV genes fall about **twice as much** as the late-maturing set, so the signal is PV-weighted, but the late-maturing set moves in the same direction in every contrast with a PV fall, together with the myelin genes. At transcript level this is **not a PV-specific deficit**; it looks like a broader neuronal and glial programme running behind or in a different state at P17, with a larger PV component. The data cannot say which of delay, late-stage illness or a true PV loss produces it.
3. **Consequence for the slice pilot (hypothesis level).** A PV-directed pharmacological arm should **not** enter the pilot as a test of "a PV-specific deficit"; RP-019 stays open and nothing here moves "transferred, not measured" to "measured" at cell level. The pilot can add a **measurement, not a drug arm**: PV and one late-maturing marker read in the same tissue with age-matched controls (section 5).
4. **Reasoned stop.** The nucleus-level route is closed by the deposit itself (IT13b's single-nucleus note, recomputed by IT14: library of origin not retained, one pooled library per arm); no cheaper in silico step is left; the laboratory pair in section 5 is the next discriminating observation. Capacity is therefore free for (B), the DNA-damage signature, if ADV wants it.

## 3. Post hoc (not pre-registered; labelled; none changes the verdict)
* **Leave-one-gene-out** (`out/sensitivity_leave_one_gene_out.tsv`): the primary verdict stays R-B on omitting any gene of the PV set, of the reference set or any late-set gene except **Slc12a5 (KCC2) -> R-D (-0.235)**. A bulk KCC2 transcript fall is also a chloride-dossier item: here it is a member of a falling late set and cannot be read as a gradient measure (composition and stage confound it; this is the same limit as ADV-065c).
* **Exact label permutation** (35 labelings of 3 animals as "knockout", label-free centring; description only, n is 3 against 4): the observed PV value is the lowest of 35 (1 of 35), the late set 2 of 35, the other interneuron set 14 of 35. So the PV and late-set falls are both unusual in the primary contrast, and the other-interneuron set is not.
* **Deletion depth across the three knockout animals** (n = 3, description): Wwox change -1.59, -1.91, -0.85; PV value minus control mean -0.72, -0.95, -0.29; late-set value -0.51, -0.30, -0.19. The animal with the weakest deletion has the smallest PV and late-set shifts, and PV tracks the deletion depth in rank order; this fits a dose-related effect of the deletion on the whole signature and does not separate the readings.

## 5. What the slice pilot should and should not include as a consequence (hypothesis level)
* **Not as a consequence of this step:** a PV-directed pharmacological comparison arm added to the pilot on the ground that a PV-specific deficit is established; the premise RP-019 is not moved by transcripts at this resolution.
* **As a cheap addition (a measurement):** tissue from the pilot's own animals read for PV (cell count and signal per cell) and for at least one late-maturing neuronal marker and one myelin marker, with **age-matched controls and at two ages** (the pilot's window and one earlier), so that "PV-specific", "falls together" and "later in the same course" make different predictions; this is the discriminating observation. Which way each outcome leans: PV cells fewer with the late markers normal favours a PV-specific loss; PV signal per cell lower with cell number normal favours a state or maturation effect; everything lower at the late age and not at the early age favours the stage-of-illness reading.
* The PV chemogenetic tool arm (IT56-Q08R) stays optional and lowest priority; the generic GABA-A modulator arm is unaffected by this result.

## 6. Limits
Bulk transcripts, not cells, not protein, not function; n of 2 to 4 per arm, so only the primary contrast gets a rule verdict, and it is at its boundary and carried by one gene; the late-maturing and reference sets are my judgement from general knowledge of postnatal expression, not a calibrated list, and Slc12a5 and Camk2a are excitatory-neuron genes, so the late set mixes "late" with "excitatory"; one cohort family and one laboratory throughout; GEO sample equals animal is assumed; TPM is compositional; no independent verifier or second reading (as assigned: no delegate unless a pivotal row needed one; the pivotal row here is the boundary verdict, and I judged the leave-one-gene-out and the permutation a sufficient bounded check on it, not an independent one). Cost: main-session turns only, no delegate; tokens not read back for this step.
