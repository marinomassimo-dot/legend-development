# I15 DISTANCE TO THRESHOLD AS THE ENDPOINT (dossier v1, ADV; free seat; HYPOTHESIS; mechanism level; not medical advice; reference genotype class only)

Written for: SCI (model owner: asked to compute the threshold in the fitted network), HE (harness), IT (second reader), the operator. Labels: HELD (source file named), MODEL (a script output, a generator, not evidence), ASSUMED, INFERRED. Seed: three independent readings of the same weakness (IT on I4 and I13, SCI's heterozygote test, HE's I13 attack) all trip on the same thing: **burst yes/no is a threshold readout that is zero in wild type**, so ratios, A/G arithmetic, "null over wild type" effects and the graded gene-dose pattern are undefined or flipped by it.

## Answer first
* **The idea.** Wwox dose does not switch bursting on; it sets a *distance to a burst threshold*. Wild type sits far from it, the heterozygote close to it, the knockout past it. Held pattern: bursting slices 0 of 11 (S-WT), 4 of 23 (S-HT), 36 of 42 (S-KO) (Breton 2021 Results, re-read in `files/fulltext/PMID34634460_Breton2021_EPMC_2026-09-27.xml`): a dose-response of an incidence is what a graded distance to a fixed threshold looks like when slice-to-slice variability is added (MODEL: SCI's `het_incidence_test.py` reproduces the shape only with a steep graded component).
* **The endpoint that follows.** For every genotype and every arm measure the *perturbation needed to make a slice burst*: a titration of a standard excitatory challenge (extracellular potassium raised in steps, or magnesium lowered in steps; the choice is ASSUMED to be a pilot detail) and read the **burst-onset concentration per slice**. It is defined in all three genotypes (wild type has a number, not zero), it is close to linear in the quantities the models use, and a drug is read as a **threshold shift** in the same units in every genotype.
* **What it fixes, with no new theory.** (i) IT's point that A and G (HE's I4 two-step) are undefined on burst rate because wild type has none: a threshold shift of an A1 antagonist is defined in wild type too. (ii) The bursting-wild-type control that IT asked for in I4 and in I13 comes for free: the wild-type slice *is* pharmacologically driven to burst at its onset concentration, so substrate sensitivity, tonic-current reserve and chloride reading can be compared at matched network state. (iii) The graded gene-dose pattern becomes a single curve (onset concentration against genotype) instead of three incidences.
* **Predictions that can fail (MODEL-level; the owners of each idea may change a sign with a reason).** P1: onset concentration is ordered S-WT > S-HT > S-KO, with S-HT clearly nearer the knockout than 0.17 would suggest if distance is the variable (a test of the 'distance' reading against the 'switch' reading). P2: a tonic-preferring GABA-A potentiator (I13) shifts the knockout's onset concentration up more than a synaptic-preferring one at the same fractional change of the same conductance; if the opposite, tonic loss is not the graded component. P3: an NMDAR pore blocker abolishes bursts at any concentration reached (no threshold exists), while a T-type-class agent and a resource-type agent move the onset in a *different direction from each other* if I1's two-stage reading is right (interval versus duration become separate readouts at the onset). P4: the onset concentration in the P47T line is intermediate or knockout-like for the features P47T copies (I8 arm), which needs no extra animals.
* **Depth: experiment-ready as a design; the model part is a request to SCI.**

## D1 Statement and chain
1. A neocortical slice bursts when excitatory drive exceeds a recovery-limited inhibitory-plus-intrinsic brake (T13, T2, I1). 2. Wwox loss lowers the brake in a graded way (the graded features of Breton 2021: rebound, mEPSC amplitude; I13 tonic conductance if the tonic current proves graded). 3. The challenge raises drive stepwise until the brake is exceeded (a standard tool; ASSUMED here). 4. The onset is the distance in drive units. 5. A drug acting on the brake or on the drive moves the onset; a drug acting on the burst after it begins (duration) does not.

## D2 Why non-obvious
The field reads each of these experiments as burst present or absent, which pools all the information near zero and forces a comparison of two silent states. The threshold endpoint is a change of *what is measured*, not of the hypothesis, and it is the form in which the existing models already express their sensitivity (SCI's 'a 20% change crosses the line').

## D3 Consequences across scales
Cell: the same onset must go with the same cell-level readouts (holding current for tonic, resting potential and input resistance for leak, E_GABA minus potential for chloride). Slice: onset concentration per slice, animal as the unit. Animal: dose-response over genotype, three ages (IT's P8-P10, P13-P15, P16-P17) shows whether the distance shrinks with the burst window. Patient: none claimed.

## D4 Model (a request, not a result)
SCI's fitted network has resting drive `b0` and noise amplitude as parameters: compute, for each of the genotype settings of `het_incidence_test.py` (S-KO, S-HT, S-WT) and for each of the 20 frozen class arms, the *drive increment needed for 50% incidence in 600 s* (a threshold, bisection), predictions written first. Report which arms move it and in which direction; a class that changes duration but not onset is an I1-type arm, one that moves onset but not duration is a brake-type arm. HE's harness can run it as a fourth frozen scan.

## D5 Discriminating experiments
(a) **No new data:** the model request above; and, if the raw burst lists of Breton 2021 are held, the relation between a burst's duration and the following interval (IT's rival test for I1) is a threshold-with-refractoriness readout in the same spirit. (b) **One slice experiment:** genotype (S-WT, S-HT, S-KO, P47T) x onset titration, with the standard arms of the brief (tonic-preferring and synaptic-preferring GABA-A potentiator labels, A1 antagonist, T-type label, NMDAR label, K+ leak opener label) each as a *threshold shift*. Reading, fixed before the first cell: 'distance' is supported if S-HT onset is in the lower third of the interval between S-WT and S-KO; the 'switch' reading if S-HT onset is within 20% of S-WT or within 20% of S-KO (the 20% margin is stated here, before any slice). (c) **Clinical-observational:** none.

## D6 Intervention logic (labels only; no dose, no agent recommended)
The endpoint does not rank agents; it makes every arm of the pilot comparable in one unit. A repurposing reading follows only from a shift in the knockout larger than in the wild type and larger than in a pharmacologically bursting wild-type control. BLOCK-1 flags from public labels apply to any named agent and none is named here.

## D7 Combination
I13 (tonic current graded?), I1 (interval and duration split at the onset), I4 (A/G defined on a threshold shift), I6 (chloride sets whether the same potentiator raises or lowers the onset), I8 (P47T copies which features). It is a measurement frame for all of them, which is its entire claim.

## D8 Stronger / dead
Stronger: S-HT onset clearly intermediate; arms ordering stable across genotypes; model onset predictions matched. Killed by test: S-HT onset equal to S-KO or to S-WT within the stated 20% margin (then it is a switch, and incidence graded only by slice variability), or onset concentration not defined (slices burst at the first step or never within physiology): the endpoint cannot be used.
