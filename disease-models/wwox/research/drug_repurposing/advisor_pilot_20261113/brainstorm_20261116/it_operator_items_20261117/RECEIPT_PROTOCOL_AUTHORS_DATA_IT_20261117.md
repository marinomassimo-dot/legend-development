# Receipt protocol for the authors' data (IT; written before any data exist; one page; non-canonical; not medical advice)
Written for: ADV (second scorer for IT's own lines), SCI (predictor of ledger L1-L4 and the sidecar), HE (scorer script), any collaborator who sends data. Lines covered: SCI's prospective ledger L1 (position of the S-HT mean sIPSC amplitude between S-KO and S-WT), L2 (S-HT versus S-WT sIPSC frequency), L3 and L4 (interval-duration correlations from the burst event lists of 119 bursts, 18 slices, 9 animals) and the matching lines of HE's ledger sidecar.
1. WHO OPENS: IT opens the file; the predictors (SCI for L1-L4) do not read it before scoring; HE's scorer script reads it only after IT's note exists, so that the two scores are independent. For lines whose predictor is IT (I2, I7, I11, I14, I17), ADV opens and scores.
2. ROUTE: the file arrives through the operator or ADV into a folder outside the repository (the Orchestrator scratchpad or a path the operator names), not through a channel the predictor reads; only the digest and the scorer's note enter the repository; if the data contain per-cell values, the file itself stays withheld unless the gate passes it and the operator agrees (the per-child rule applies to cells and animals as it does to children).
3. DIGEST: on receipt IT computes sha256 of every received file and records it BEFORE opening it; the sender states the digest of what was sent; a mismatch stops the scoring until the sender confirms the file; no file is edited, converted or filtered before the digest is recorded.
4. RECORD (one block in IT's task record per delivery): date and time received, who sent it (named person or channel as the operator states it), the digest of each file, the unit and count stated by the sender (cells, animals, slices, bursts, events), the observed value of every ledger quantity with its locator (file, sheet or table, row, column), and the line it scores.
5. SCORING RULE: a line is scored by its registered bin as written in the ledger commit; limits (n, intervals, readability) are notes, never exclusions (ADV's ruling on L10a). The probability assigned to the observed bin gives the log score; the naive baseline is scored the same way.
6. PARTIAL OR DIFFERENTLY-UNITED DELIVERY: a partial delivery scores only the lines it actually covers (for example L1 and L2 if only the sIPSC values arrive; L3 and L4 stay open); a delivery in a different unit than the registered one (for example per-animal means instead of per-cell values, or per-slice instead of per-burst) is recorded with the unit change stated, and a line is scored only if its registered quantity can be computed in the delivered unit without changing the definition; otherwise the line is marked 'not scorable in the delivered unit' (not zero, not neutral) and stays open for a delivery in the registered unit. If the sender cannot supply the registered unit, SCI may register a new line in the delivered unit BEFORE the data are opened (a new version with a new digest); it cannot be applied retroactively.
7. SECOND SCORER: ADV re-scores IT's own lines and checks the arithmetic of IT's scores for SCI's lines; HE's script reproduces both when it exists; any disagreement is written next to the score, not resolved by editing.
8. WHAT IS NOT RECORDED: free-text comments of the sender about interpretation are kept in the delivery note but are not evidence; no value is rounded or recomputed from a figure when a table exists.
