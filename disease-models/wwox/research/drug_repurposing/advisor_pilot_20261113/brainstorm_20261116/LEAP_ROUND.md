# LEAP ROUND (ADV; extends PLAN_8H from 08:25Z; non-canonical; not medical advice)

Purpose: item 1 asks for NEW hypotheses that reach an experiment and a drug-repurposing step, and the operator allowed divergent thinking. The matrix ranks what the held evidence already says; it cannot invent. This round tests whether deliberate leaps (a changed perspective) produce hypotheses that survive a blind check better than a memory-free simple search, at what cost. Mechanism and repurposing-class level only: no dose, no recommendation to use any agent, BLOCK-1 before any candidate row, reference genotype class only, lawful public sources, a reCAPTCHA or interstitial is a stop, zero spend.

## Template (one block per hypothesis, at most 5 per author, one file per author)
H<author>-<n>. Perspective used (one of the list below, named) · Statement (a mechanism, one sentence, with a rejecting observation) · Why a leap (what the usual reading assumes and this one drops) · Existing assay or held table that can test it (path) · The single discriminating observation and its two outcomes (what each changes in the matrix top set or a card) · Repurposing class and 2 named examples ONLY as labels (source for the mechanism, no dose) · Held-data pre-test (can a held table already reject it? result) · What would change my mind · Cost to test (rough, in animals or table lookups).

## Perspectives (assigned so that the four authors do not converge)
* SCI: ion gradients and network dynamics (chloride reversal and KCC2/NKCC1 given the 12 mM pipette finding and the bursts; excitatory GABA early; T-type rebound; the neocortex versus hippocampus split; homeostatic plasticity after the burst).
* IT: development and clinical time structure (infantile-spasm window, why seizure control and development are discordant in 4 of 6, drug-resistance as a clue, which endpoint each thread could own, base rates from other DEEs as priors).
* HE: data and measurement (what the held expression/signature tables, the LINCS-type census and the registry counts imply that nobody has asked; where a hypothesis can be rejected by a table already in the repository; which repeated artefact in the repository looks like a signal).
* ADV: cross-disease and metabolic/glial (nearest DEE electrophenotype by analogy, ketogenic/metabolic route, myelin and OPC, ISR, JNK, WWOX as a scaffold: what do its binding partners imply for excitability).

## Rules
1. Generate first, alone, without reading each other's files; freeze each author's file by commit hash (HE's ledger: kind generative, predictor = author). 2. IT launches ONE memory-free baseline-arm delegate with the same question and the same template and NO repository files beyond the bundle used for the matrix baseline arm; its output frozen by hash BEFORE anyone reads the authors' files. 3. A blind judge (a delegate, not an author, one active delegate at a time) scores every hypothesis from both arms WITHOUT knowing which arm wrote it, on four yes/no/partial criteria fixed here: (a) not already in the repository's cards, open-question map or INV rows (novel), (b) testable on a named existing assay or held table, (c) states a rejecting observation, (d) survives the held-data pre-test (no held table already rejects it). A hypothesis 'survives' if it is novel AND testable AND states a rejecting observation AND is not already rejected. 4. Metrics: survivors per author and per arm; survivors per 10,000 output tokens (authors' tokens from session_model_census, the baseline arm's from its reading); the share of survivors that came from a changed perspective (the author flags which one); IT's stop rule: if the baseline arm equals the authors in three consecutive rounds, the leap step is not worth its cost. 5. The top 3 survivors by the judge become the prospective registry's generative entries (dated outcome sources) and, if one has a cheap held-data test, it is run at once by its author's counterpart. 6. Nothing changes a card, row or ranking from this round; consumption only as dated Updates after a second read.
