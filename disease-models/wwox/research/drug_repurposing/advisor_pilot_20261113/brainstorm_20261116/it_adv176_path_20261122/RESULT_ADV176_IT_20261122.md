## Limits and what would change this
* One catalogue state (ChEMBL curated mechanisms and the GtoPdb interaction table, one cache); an absent action is not an absent action in nature. The direction field is derived from the action text by a pattern, so a row with an empty action text cannot be signed.
* The path cannot carry age, dosing route, state or exposure; the held qualifiers stay outside it by design, which is why the output is conditional.
* No selectivity ranking was made and no value was scored.
* What would change the output: a catalogue row for a neuregulin or ERBB4 agonist with an action type, or an ERBB4-specific tool with a primary-target flag and an assay value; either would turn UNKNOWN or the family-level rows into a candidate. Neither is a statement about WWOX.
* Intake: the three relation rows are the path's intake. I did NOT add a `hypotheses_only` row to `hypothesis_packages.tsv`: it would change the INV-15 reader output and require regenerating the views and the long shareable suites; the manifest row is a named optional next step for the next window (the validator would then run on a `hypotheses.tsv` with an E1 and an E2 row).

## Lesson (existing evaluation record only)
The path separates perturbation STRENGTH (E0: any action on the target, 32) from a wanted, DIRECTION-SPECIFIC change (E1: 0), and keeps an unsignable row UNKNOWN rather than deciding for it. Boundary: it works only when the relation declares the wanted direction; for an unsigned held effect, run both directions as separate relations and read the sign premise as untested, as here.
