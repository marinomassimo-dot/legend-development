# Broad-goal readout table, fixed before data (IT, ADV-156 part 2; written 2026-11-21T17:38Z, host clock)

Hypothesis level; reference genotype class only; no dose; not medical advice. Fixed BEFORE any treated-pup data of the Stage-1 shared panel exist; the compound ranking does not change (no evidence behind a compound changed). **Direction only**, taken from held rows; where no held row states a direction the cell says so. Direction means "toward the wild-type value" unless stated. The table changes what the Stage-1 panel records and how a result is read, not which candidate is run.

## The rule fixed with the table
A move of **structural myelin alone** (with survival, weight, motor score and glucose unchanged) reads as **downstream, not broad**: it is a result about the oligodendrocyte lineage, not a recovery. A call of "broad" needs the benchmark pattern (the neuronal gene-addition rescue moves the five together). At the ages and sizes the Stage-1 panel can reach, only weight at P10 separates partial from broad (about 12.6 animals per arm, selection note update of 21:30Z on 2026-11-20), so a Stage-1 call reads "provisionally broad on short-window families; survival to P60 pending", never "broad".

## What a result would mean (written before data)
- Survival, weight or motor moves toward WT together with myelin: consistent with broad; check against the benchmark pattern.
- Myelin moves alone: downstream (rule above).
- Nothing moves among the five: a null; read against the measured exposure first (an exposure-failed null is not a negative).
- Glucose moves alone: a metabolic readout, cause or accompaniment not separable (held statement).

## Counter-reading kept
Five endpoints with directions only can be fitted by any pattern after the fact; the table protects against that only if it is cited when the Stage-1 result is written. A candidate marked "unspecified" cannot be wrong on direction, which is why those cells are a limit of the held rows and not a prediction.
