## 2. ADV's comparison of the options (the scoring language of the prior is applied)
- **O1 circuit pilot: NOT NOW.** All three contributors independently say the held data cannot separate the rivals (SCI), the simulator can only tie or fail at an effective n of 2 to 4 (HE) and its prediction would not change which compound goes first (IT). A pilot whose best outcome is a tie, built on assumed parameters re-fitted to two numbers of one study, spends the team on the least informative option. Kept as the FALLBACK with named triggers.
- **O2 organoid per-line withheld endpoint: the smallest real candidate (P-SCI-1).** ADV's own check: the four lines are two per genotype, so under the null of no genotype effect the probability that both WOREE lines exceed both SCAR12 lines is 1 in 6 (about 0.17). A full pass is therefore a TIE by HE's rule, not an improvement; its value is asymmetric: ONE reversed pairing refutes the genotype reading of the printed 3.4-fold gap (row G, a line or batch effect). It is falsification-only, like the circuit pilot, but it costs nothing, it needs no model, and it is about a contrast that decides whether the WOREE-over-SCAR12 statement stays a ranking input. Its status if the table never comes: a dated, possibly never-evaluated forecast (recorded as unevaluable, never as success).
- **O3 pre-registered rule with no new model: ADOPTED as the form.** The forecast is written once, frozen by commit before any outcome, with two forecasters in one file (genotype-effect; line-or-batch effect) plus the evidence-only reading, per HE's format. This is what makes any later release scorable at no extra cost.
- **O4 'no design changes the decision': TRUE FOR THE ORDER OF FIRST EXPERIMENTS.** The order is set by what is unmeasured (exposure with genotype-by-treatment contrast; E_GABA; a per-animal EEG with cell identity), not by any simulated or per-line prediction. IT's reading that the adjunctive decision rests on exposure and harm per age, not target action, is the likelier one and is recorded as INFERENCE.

## 3. DECISION (ADV host)
1. **No current in-silico design changes which experiment or comparison goes first.** Exact reasons: the rivals are not separated by any held measurement (SCI); the model's predictions cannot be scored as an improvement at n of 2 to 4 (HE); the compound order is set by exposure and by unmeasured links (IT).
2. **The small instrument chosen is a FORECAST FREEZE, falsification-only, with improvement declared UNREACHABLE on the data that can exist soon:** entry 1 = P-SCI-1 (per-line week-16 event-rate ordering), comparator forecasters = genotype-effect, line-or-batch effect, and the evidence-only reading; reading rule: reversed pairing = refutation of the genotype reading; all four pairings in order and in range = TIE (p floor 1/6); missing line labels, batch labels or ROI denominators = UNEVALUABLE. Which outcomes would count as an IMPROVEMENT at all: five or more independent outcomes from five or more laboratory-and-cohort clusters (HE), of which only two are named today (the Nappi per-animal data; the Aqeilan per-line table), one cluster each.
3. **What it changes in the programme (decision-relevant elements only):** (a) whether the WOREE-over-SCAR12 contrast stays a ranking input or is carried as pooled-only (row G); (b) one readout table fixed BEFORE data for the broad goal (which of survival, weight, motor, structural myelin, glucose each candidate is expected to move; a myelin-only move then reads as downstream), changing the Stage-1 panel, not the candidate (IT); (c) three claims demoted (simulated class order as an argument for the tonic arm; Kv7 until a margin is measured; the T-type attribution arm).
4. **FALLBACK, with triggers, not scheduled:** the circuit pilot under HE's three rules (re-fit to the same held numbers; sidecar forecasts; paired fixed-strength design with 10 or more seeds; about 360 to 720 simulations, 1 to 2 hours, removable by one folder) PLUS a built structural rival (a Kv7 current or a second interneuron class). Triggers: the first of (i) E_GABA in a Wwox system, (ii) per-animal EEG with cell identity and age (AES poster on 5 December, if it prints them), (iii) a second independent-laboratory burst interval or duration report in the same system. Until one fires, no compute is spent.
5. **Both goals stay separate:** broad developmental recovery (persisting, co-moving endpoints; the oscillator is irrelevant to it) and the narrower adjunctive goal (a provoked or spontaneous seizure endpoint at one age with exposure and harm cells). A result in one is not spent in the other.
6. **Strongest counter-explanation held against the whole choice:** a forecast freeze that can only tie or fail is a cheap record, not a capacity; it earns its place only if it is scored when data arrive and if the broad-goal readout table and the three demotions are actually used by the next batch. If no release arrives, the honest statement is 'no predictive capacity tested'.
7. **Not done and why:** no simulation was run; no ranking change (the compound ranking changes only if the evidence behind it changes); no outreach (a request for the per-line table or per-animal data would be outreach and is outside this meeting).
