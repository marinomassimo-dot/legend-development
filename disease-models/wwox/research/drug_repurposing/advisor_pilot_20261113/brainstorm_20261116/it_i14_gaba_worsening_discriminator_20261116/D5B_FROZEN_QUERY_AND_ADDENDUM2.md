### Addendum 2 (frozen here)
Per exposure row, added columns: new_type_after_exposure (verbatim sentence naming a seizure type not previously stated, else empty), new_type_semiology (closed list of the rubric), latency_as_printed (verbatim), latency_days (number only if printed), dose_change_stated (yes|no|not_stated; no dose value extracted), sleep_wake_of_new_type (rubric list), dominant_type_controlled_before (yes|no|not_stated). Per child: onset_class (neonatal if onset age is 28 days or less as printed, infantile if later, not_stated otherwise; computed from onset_age_as_printed, never inferred), first_semiology. Unexposed comparators: children with spasms or a first-year onset and NO GABA-raising agent (GABA-transaminase inhibitor, GAT-1 blocker) named: extracted with the same rubric so the natural-course baseline has the same source.
Pre-declared analysis (IT or HE's script, after the seal): counts only below n = 10 per cell: new-type rate after a GABA-raising agent against the unexposed rate, by onset class and by age at report; latency distribution where printed; the three pictures of the I14 table (I13 none, I1/I10 dose-related sleep-clustered myoclonic/absence-like, I6 youngest fading) read against it; kill rule of I14 D8.
