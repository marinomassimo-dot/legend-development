# I16 Two onset classes: a neonatal-onset circuit that the rebound picture cannot reach (dossier v1; IT; non-canonical; hypothesis; not medical advice)

Written for: ADV (cross-reading), SCI (I6, I7, I10 owners of the competing readings), HE, a clinician-researcher. Reference genotype class only; mechanism level; no agent recommended; BLOCK-1 flags from public labels, not run. Status ADVANCE; depth chain. Labels: KNOWN / HELD-DATA / ASSUMED / INFERRED. All counts are post hoc from the sealed per-child table (`it_i2_semiology_20261116/extraction_v1`).

**Answer first.** The leading picture of the day (rebound ignition under a failed neocortical brake; slices at P13-P17; thalamocortical state dependence) is a picture of INFANTILE-onset events. The held children do not all start in infancy: of 37 children with a numeric onset, 11 start before 1 month and 4 in the first days of life (0.02, 0.03, 0.03, 0.07 months; Oliver and Chong reports); the median is 2.0 months. A seizure in the first days cannot come from a thalamocortical spindle-state network. If the genotype class has two onset classes, neonatal (about 28 days or less) and infantile, they would be two circuits with two pharmacologies, and the picture explains only the second. The test needs onset class as a stratifier, which the D5b other-report extraction already records.

## D1 Chain
1. Onset ages in the reference class span days to months (HELD-DATA: 37 children; ordered values 0.02, 0.03, 0.03, 0.07, 0.23, 0.46, 0.56, 0.62, 0.69, 0.76, 0.92, then 1.0 to 10).
2. Onset class does not sort by genotype class in the one report that tabulates both (HELD-DATA, Oliver 13 children: null/null onsets from 0.23 to 10 months; missense/missense 1.0 and 1.12; missense/null 0.03 to 2.5): so genotype severity does not alone set the onset class (ASSUMED reading; n 13).
3. Around birth the cortical network has depolarising or weakly hyperpolarising GABA, a high GluN2B share and no mature thalamocortical rhythms (KNOWN in general; the wild-type GluN2B share 53% at P6-P8 is HELD-DATA, Mierau 2004), so events at this age need a different mechanism from sleep-state rebound (INFERRED).
4. The held mouse slice bursts are recorded P13-P17 and the onset in vivo is stated from about P9 (E11 of the INV-06 table; not re-read); if mouse P0-P9 maps to the human neonatal period (a common approximation, ASSUMED), the mouse window before P9 is the equivalent of the neonatal class and nothing in the held data covers it.
5. So the neonatal class predicts a pharmacology of its own: poor response to GABA-A positive modulators (depolarising GABA), response to an NKCC1-directed or GluN2B-directed route (I6, I7).

## D2 Why non-obvious
The matrix and the pictures of the day pool all children as 'the genotype class' and use one mouse window as the model. This reads the repository's own onset ages as a discriminator of the picture and asks which children the picture cannot explain.

## D3 Consequences across scales
* Cell/slice: null cortex at P5-P9 should show events or hyperexcitability whose sensitivity differs from P13-P17: ifenprodil-sensitive share higher (53% in wild type at P6-P8), chloride-dependent GABA action (gramicidin-perforated measurement), no spindle-range structure.
* Animal: onset of EEG events before P9 in the null; if none are found before P9, the neonatal class has no mouse correlate and the class is human-specific or driven by something other than the neuron-deleted line (a genotype difference between the line and the children).
* Patient: onset class (days) versus infantile onset should differ in first semiology (focal motor, tonic, status first in the neonatal class: HELD-DATA: neonatal-onset Oliver children carry focal_motor and tonic types in their lists), response to GABA-A PAMs, and development.
* **Surprising prediction.** GABA-A positive modulators (phenobarbital and benzodiazepine class) work WORSE in the neonatal class than in the infantile one, while the class of GABA-transaminase inhibitors and steroid/ACTH does not differ. The opposite of what a rebound picture says about the same agents (they aggravate the late class).
First look (post hoc, labelled; n far below any claim): GABA-A positive modulator exposures with a stated outcome, onset under 1 month: 1 resolved, 1 partial, 2 none (3 children); onset 1 month or later: 2 resolved, 1 partial, 5 none (4 children). Uninformative.

## D4 Model
SCI's I6 chloride model (activity-dependent chloride loading, GABA-A PAM sign) with the initial intracellular chloride set to a neonatal value is the natural model; the prediction of I6 is that the sign of a PAM flips with the starting chloride. A model run is not done by me; request to SCI/HE harness: scan the PAM sign against initial chloride.

## D5 Discriminating experiments
(a) No new data: exhausted for the 14 reports (above). The per-child table can still give: onset class against first semiology and against development outcome (counts), a cheap table edit.
(b) Slice/animal: null and wild-type neocortical slices at P6-P9: isolated NMDAR current with ifenprodil (shares the I7 experiment at an early age), perforated-patch E_GABA, burst or event incidence with d-APV versus an NKCC1-directed and a GluN2B-directed tool; in vivo EEG from P5 in the null pup (the I10 experiment, started earlier). Outcomes: events before P9 with chloride- and GluN2B-dependent pharmacology = a neonatal circuit exists in the mouse; none before P9 = the class has no mouse correlate in this line.
(c) Clinical-observational: in the D5b other-report extraction, record onset age and stratify at 28 days; for each GABA-A positive modulator exposure record the outcome by class; a clinician-researcher can add the same stratifier to any seizure diary.

## D6 Intervention logic (labels, no recommendation)
NKCC1-directed route (label: bumetanide; a public boxed warning on profound diuresis and electrolyte loss; ototoxicity is a known class concern; red by label); GluN2B NAM class (label: radiprodil, a tool/clinical-stage compound); aggravation counterpart: GABA-A positive modulators in the neonatal class if GABA is depolarising (phenobarbital, benzodiazepines: red by boxed warning for the benzodiazepine class). BLOCK-1 not run; flags from public labels.

## D7 Combination
I6 (chloride), I7 (early window, GluN2B), I2 (semiology and age), I10 (late class). The unified picture becomes two circuits, early (chloride/GluN2B-dependent, non-thalamocortical) and late (rebound, thalamocortical), not one. Contradiction to settle: the held mouse onset (about P9) places mouse events at the edge between the classes.

## D8 Stronger / killed
Stronger: pups with events before P9 and chloride/GluN2B pharmacology; neonatal-onset children with a different first semiology and PAM response in an independent extraction. Killed by a test: in the D5b extraction (n of 10 or more children per onset class) the first semiology, the PAM response and the development outcome do not differ between onset classes; then onset age is a continuous severity variable and I16 reduces to age.
