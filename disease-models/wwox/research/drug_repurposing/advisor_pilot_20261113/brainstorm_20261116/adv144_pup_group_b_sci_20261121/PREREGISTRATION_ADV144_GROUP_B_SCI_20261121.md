## Part 1 rule: the sizing arithmetic (C06)
1. **Inputs are only those the addendum states** (CV of the outcome S, within-animal correlation, ratio, power, alpha, floor-bound WT arms). Any input the addendum does not state is **not assumed**: I name it, show the result for the range the record itself implies, and say which input moves the answer.
2. **Method fixed now:** two-sided alpha 0.05 and power 0.80 unless the addendum states otherwise (then its values); outcome analysed on the log scale with SD_log = sqrt(ln(1 + CV^2)); the simple effect is a ratio R of two independent-animal arms (variance 2 SD_log^2 per n, using a within-animal correlation only where the design is a paired within-animal contrast, as the addendum says); the interaction contrast is the difference of two simple effects across two strata, variance 4 SD_log^2 per n for independent cells (twice the simple effect's variance when both effects are of equal size, so equal n per cell is doubled only if the interaction effect equals the simple effect). Normal-approximation formula n = (z_(1-alpha/2) + z_(1-beta))^2 x variance-factor x SD_log^2 / delta^2; a t-correction is reported as a second column.
3. **Two statements are comparable only if they name the same contrast, the same effect size delta and the same variance structure.** If they differ, I say which differs and restate both on one contrast. If one cannot be reproduced from stated inputs, it is an error to correct (dated line in `fig7_quant_ethosuximide_lithium_sci_20261115`), not a re-interpretation.
4. **Blind recompute** by a delegate of a different model, given only the stated inputs and the formula request (not my numbers, not the addendum's), effort stated in the brief and read back from its transcript if the harness allows. Tolerance: agreement within 5 percent of n on the normal approximation.
