* **Near controls.** Model (`RIVALS_RESULT_SCI.md` Update v2): measured phasic deficit + small excitatory gradient + graded rebound reproduces 0 / 17 / 86% inside the binomial windows. Conclusion: the incidence is explained by measured quantities; tonic (I13) and chloride (I6) are allowed, not needed; the S-HT tonic-current and E_GABA arms test only whether something beyond the phasic deficit contributes (low prior); I13 stays parked for the incidence question, I6 likewise.
* **Midway.** The model with phasic alone fails (S-HT 0.55 to 0.78 against a held 0.17; binomial window 5 to 39%). Conclusion: a further graded component steeper than the phasic one must carry S-HT; in the model the smallest additions that bring S-HT into the window are given by the run `midway_additions.tsv` (predictions below), so the S-HT tonic-current arm and the E_GABA arm become DECISIVE for the incidence (intermediate S-HT value in one of them is the prediction), I13 and I6 return as explanatory candidates, and the first measurement is the S-HT tonic current.
* **Near knockout.** Phasic inhibition cannot carry the 0 / 17 / 86% gradient (S-HT would burst like S-KO in the model); the graded factor must be elsewhere (rebound, tonic, chloride, glial, size); the held KS test of S-HT against S-KO sIPSC (p 2.5e-69 for amplitude) makes this the least likely case; if it occurs I would treat the sIPSC deficit as not explanatory and run the full rival ladder again with S-HT fixed at the knockout value for phasic.
* **Not separable.** The author request for the Fig. 4 source data (operator item) stays the only route; until then the model's statement is conditional on S-HT near controls, which the KS tests (S-HT against S-KO) support but do not prove.
