# Duration against the following interval in the fitted oscillator: predictions written BEFORE the run (SCI, 2026-11-16; ADV's request item 3; MODEL, hypothesis generator, not evidence)
Context: IT's one-stage rival (a threshold with refractoriness) predicts the interval after a burst depends on that burst's duration; ADV reads I1 as predicting independence. The held data do NOT contain the per-burst list (Breton 2021 gives medians, gamma shape parameters duration 2.45 [1.93-3.11] for 119 bursts and interval 1.43 [1.11-1.84] for 101 intervals, 18 slices, 9 animals; Supplementary Table S1 is group-level), so the test is run on the model only.
Prediction for the fitted frozen oscillator (300 networks of 900 s, bursts > 0.1 s; Spearman rho within network, averaged over networks with at least 8 bursts, and pooled with the network as cluster):
C1. rho(burst duration, FOLLOWING interval) is POSITIVE, between +0.05 and +0.35: the oscillator is not independent, because a longer burst depletes more synaptic resource, adenosine and the T-type-like availability, all of which recover over seconds to tens of seconds (resource tau 6 s, trigger tau 15.7 s).
C2. rho(PRECEDING interval, burst duration) is positive, between 0.0 and +0.30 (a longer rest lets resource and trigger recover more, so the next burst is longer).
C3. The pooled rho across networks is no larger than the within-network mean by more than 0.1 (no between-network confound: the networks share one parameter set).
Reading: the verbal two-stage statement 'the trigger sets the interval and the sustainer sets the duration' is a statement about which parameter controls which quantity (the T-type weight changes the interval and not the duration: held in the model: interval +92%, duration +5%), not a statement of independence of the two sequences; if C1 holds, the independence version of I1 is not what the model says, and a correlation test cannot separate I1 from the one-stage rival unless it is compared with the rival's own predicted rho.
Falsification of this paragraph: |rho| < 0.03 for C1 would say the model's sequences are independent.
