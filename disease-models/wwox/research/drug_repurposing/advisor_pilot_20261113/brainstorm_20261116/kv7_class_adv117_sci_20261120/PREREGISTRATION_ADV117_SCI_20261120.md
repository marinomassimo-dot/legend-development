## Row structure (exploration is not gated by promotion criteria)
Each row: source anchor and depth (FULL TEXT, PASSAGE, ABSTRACT, TITLE only); context (species, age, preparation, readout); what was found; **a competing explanation**; **the observation that would weaken the idea**. "Juvenile exposure not found" is recorded as "not found by these routes", never as "incompatible". Promotion criteria are not applied as filters. An absence claim needs **two routes** (two differently built queries, or a search plus a held-source check).

## Labels fixed now
* **NOT FOUND BY THESE ROUTES** (a search shape, not an absence); **ONE ORIGIN** where two values come from one document or one laboratory; **ABSTRACT** where only the abstract was read; **GAIN OR LOSS OF FUNCTION** is stated only where the source states the functional class of the variant, never inferred from the variant name.
* A Kv7 agent's **window** is the ratio of the brain concentration for the motor-impairment readout to the brain concentration for the efficacy readout inside **one document**; a ratio across documents is not computed.
* **Conditional pilot arm** means eligible on the 6.14 condition (tolerable pup exposure measured AND no pup tolerability signal); **slice priority slot** means a place, beyond ezogabine, in the 6.17 session (for example the blocker control or a subtype-selective tool); either may be answered "neither".

## Closing-paragraph decision rule (fixed before the searches)
* **The Brown 2016 apoptosis signal after repeated dosing in P7 rat pups is a pup tolerability signal for the class on the 6.14 condition unless a source read in this task shows it is explained away** (a dose far above any exposure of interest, a different outcome measure, or a failure to replicate); the default for **ezogabine is therefore: not eligible as a pilot arm now**.
* A **conditional pilot arm** is named only for an agent for which (a) a juvenile or paediatric exposure is reported AND (b) no pup tolerability signal is on record AND (c) a within-document window is reported. If no agent meets all three: the answer is "slice priority slot or neither", stated as that.
* The **slice priority slot** is answered for two additions only: XE991 reversal (attribution to Kv7 if ezogabine acts at 10 uM or less) and ICA-069673 (KCNQ2-containing channels against KCNQ3/KCNQ5 contrast); each is chosen only if the Q1 rows hold a within-document contrast for it.
* The statement "what reorders the bridge preference (ethosuximide weakly over the class)" is a list of observations, each with the direction it moves the preference, not a verdict.
