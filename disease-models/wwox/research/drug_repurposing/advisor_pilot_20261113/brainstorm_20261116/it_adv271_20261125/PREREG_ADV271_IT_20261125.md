## Definitions fixed now
* **Direction of a readout** = sign of (WWOX-null minus add-back), the add-back line being the comparator; an unrelated parental or empty-vector line is NOT the comparator and is carried only as a labelled aside.
* **Agrees with the fly** = null higher than add-back for an ISR-output readout (p-eIF2A relative to total eIF2A, ATF4, CHOP, p-PERK, p-IRE1, XBP1s, BiP, GADD34 and similar). **Agrees with the organoid** = null lower than add-back for the same readout. A UPR-arm readout that is not an ISR output (IRE1/XBP1s) is reported in its own arm and is not counted for either system.
* **A direction is "stated"** only if (a) the band or bar is named by figure, panel and lane (or bar order), (b) the loading or total-protein control of that panel is named, (c) it is quantified in print or read as clearly larger on a single-blot basis with the label "one blot, not quantified", (d) the number of independent experiments and of clones is read from the legend or Methods and written beside the direction; lanes and technical replicates are not independent units (ADV-247); (e) it is not read from position alone: lane labels are checked against the legend text (the Rempel label-by-position error is the reason).
* **Rejecting observations** (set before looking): the "agrees with the fly" reading for a readout is rejected if null is lower than or equal to add-back in the stated quantification; "agrees with the organoid" is rejected if null is higher; either is **not decidable** if there is only one clone, one unquantified blot, or a comparator other than the add-back.
* **Overall disposition grid for R-10:** (A) the isogenic pair gives a stated direction for at least one ISR-output readout with n named: R-10 may state it with the system named (non-neural), the neural sign stays UNRESOLVED; (B) the pair gives no ISR-output readout, or only unquantified single blots: R-10 stays UNRESOLVED and the missing measurement is named; (C) directions conflict between readouts of the same pair: reported as such, no summary direction.
* A pair that agrees with the fly does NOT license the neural claim: it differs in tissue, cause (a tumour line with a WWOX-null background), and amyloid conditionality; an agreement with the organoid would be equally non-neural. The aside is only a tally of directions.
* Absence rule: "not measured" is written only after the legends, main text and the two supplement files have been searched (two routes).
