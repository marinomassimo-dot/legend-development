## Inclusion rule for "reproducible"
A phenotype class counts as reproducible only if the held record (registry claims, working model lines, receipts, open-questions map) shows it in at least two independent units: two papers or laboratories, or one paper with two independent systems (species, model type or cell type). One source is "single-source": it can enter the ranking as a labelled lead, scored at most 1 on criterion (a). A class backed only by a retracted or integrity-excluded source is excluded (the HGF/Met-TAZ-WWOX bone-metastasis line named in the working model). I check reproducibility from the registry and model lines and receipts, not by re-reading papers; this is a stated limit.

## Coverage map rule (built from the dossiers' own decision lines)
For each of the 58 dossiers I take the "Current decision" paragraph (first paragraph of its README after the title; if none, the first 600 characters) by script and record it verbatim in a table with its path. I then label each class per dossier by hand: DIRECT = the dossier's named question or readout is that class; ADJACENT = the class appears only as a competing explanation, control or secondary readout; NONE otherwise. A class is **reached** with at least one DIRECT dossier, **thinly reached** if all its DIRECT dossiers are parked on the same missing anchor, and a **gap** with zero DIRECT dossiers. Label decisions go in the table with the quoted words that justify them.

## Carried-by rule
Before ranking, each gap is checked against INV-01 to INV-08 and the RP rows (opportunity and next-action text). A gap whose question is the INV or RP row's question is reported as **covered by that row** and is not ranked. Duplication of a colleague's work is avoided that way.

## Ranking (at most five; fixed before scoring)
Each remaining gap needs all four fields or it is dropped from the ranking: the phenotype with its held source and replication unit; a molecule or class that could act on it (other drug classes allowed, no dose); an opposing mechanism that would make it fail; an accessible outcome that would discriminate. Score 0 to 2 on each of: (a) strength and replication (2: two independent held units; 1: one strong or two weak; 0: single and weak); (b) a held source that can test the molecule's mechanism (2: processed table or full text held; 1: abstract-level or one indirect set; 0: none); (c) a decision the result would change (2: it would select or deselect a strand; 1: it might; 0: no); (d) pediatric feasibility as the README defines it (2: formulation, pediatric experience, exposure at site and an interpretable endpoint all identified; 1: partial; 0: unknown, recorded as a gap). Total 0 to 8; ties broken by (b), then (c). Recommend the top one. The one to drop is the lowest-scoring ranked gap, or, if the map shows a class carrying three or more DIRECT dossiers all parked on one missing anchor, that over-covered strand is named as the one not to extend and the lowest gap is named separately. Negative results already on record are listed for each reached class and are not re-opened here.
