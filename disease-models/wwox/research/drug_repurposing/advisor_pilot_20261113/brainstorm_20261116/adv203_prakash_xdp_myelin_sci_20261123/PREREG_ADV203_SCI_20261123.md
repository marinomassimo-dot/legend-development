## Question (frozen)

## The three disposition tests (frozen before reading Fig 5)
* **T-a (close the causal transfer as untested).** Holds if ALL of these are found in the paper: (1) the endpoints are cross-sectional (one age or stage per comparison, no trajectory); (2) the endpoints that would separate maturation from loss from injury are not measured in the same region and age of the same animals (any one of the four named endpoints is in a different region or stage from another); (3) the cell fractions rest on three animals per genotype or fewer, or the model is a broad lineage model (for example a Nestin-lineage driver) rather than a restricted one. If T-a holds, the disposition is (a): the transfer is untested and the output names at most ONE source-linked readout constraint that neither INV-06 nor ADV-181's rule already states, or none.
* **T-b (the source adds a readout constraint).** Holds only if the paper contains a measurement property I can locate by figure or table and that INV-06 as stated lacks and ADV-181 did not give: for example the same animals and the same region carrying a lineage fraction, a precursor fraction and ultrastructure together, a named denominator for each fraction (marker-positive of total nuclei versus of the lineage), or an explicit age-matching rule. I will state the constraint in one sentence with its locator.
* **T-c (duplicate).** Holds if the constraint I would name is already in INV-06, in the RP-017 row, or in ADV-181's rule. I will say where.
* **Restricted-cell comparison.** Counts as support for an intrinsic deficit only if the paper contains a cell-type-restricted perturbation (conditional deletion in the lineage, or a co-culture, graft or conditioned-medium comparison) read with the same endpoints; a global or broad-lineage model, or injury assessed in the same animals, does not count.
* A stop is a valid result: if the full text cannot be read from a plain route, the disposition is "not assessable" and nothing is claimed.
