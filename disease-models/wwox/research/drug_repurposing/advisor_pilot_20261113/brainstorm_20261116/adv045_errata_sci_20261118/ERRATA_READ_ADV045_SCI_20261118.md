## Method and limits
* Erratum text: read from the page or the Europe PMC full-text XML served by plain request (empty User-Agent, no key, no contact parameter, one request per route, one pause between requests). A challenge page stopped that route; nothing was retried. Raw bytes: `files/fulltext/errata_adv045_20261118/` (gitignored, root checkout), sha256 and size per file in the last section.
* "Citation only" notices (five) were found by citation in Europe PMC (journal, year, page or title): 21822218 and 25186741 and 23536761 via the PMC correction record, 22622579 via Crossref (a metadata search, no key), 24209626 only as a notice record without text.
* Locators: from `fulltext_read_receipts.jsonl` (the rows named per paper). Consumers: `git grep` by PMID in the worktree on main at the time of reading, excluding the ledger, generated census files and the notice sweep itself.
* A receipt's quote can be a text statement whose figure panel the receipt never opened (most of these receipts: figures `not_read` or `captions_only`). "Not cited" below means the locator and the consumer row name no such panel or table; it does not say the underlying paper statement rests on no other panel.
