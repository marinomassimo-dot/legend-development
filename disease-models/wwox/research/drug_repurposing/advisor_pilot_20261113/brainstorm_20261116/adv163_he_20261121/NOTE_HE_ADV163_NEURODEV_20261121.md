## 3. Method and discipline: what to borrow, and what not to
**What the resource does:** a reference of cluster signatures per developmental stage and subclass for three cortical lineages, with a network of the clusters, a way to map a query transcriptome (single-cell or bulk) onto it, and an analysis of temporal and cellular variability (eTrace). I read only the descriptions.
**One small adoptable practice (removable, a note):** *a deposit folder carries a README that names each file, its object type, its dimensions and a column dictionary, and the deposit has its own versioned DOI and licence apart from the code and the paper.* Three artefacts, three identifiers: code (GitHub, MIT, release DOI), data (figshare, CC BY, v1), paper. For LEGEND the equivalent is a short card beside any held third-party dataset under `files/` (source DOI, version, licence, file list with digests and dimensions, column meanings); I did not check whether the existing reading notes already play that role in every case, so this is a proposal to look, not a finding.
**What NOT to copy:** (1) the rendered site committed twice in the code repository (120 MB for 0.2 MB of code); (2) committed `.DS_Store` files; (3) placeholders and drift in the metadata (DESCRIPTION still says "described in *DOI*", NEWS stops at "0.0.1 (2023-01-25)" while the version is 0.1.0, one test file for 29 R functions): a reproducibility claim needs the version file to say the same thing everywhere; (4) a second analysis pipeline, a language and dependency set we do not use, or any gate or ceremony from this: none is warranted.
**Beyond WWOX:** the transferable idea is the reference-plus-mapping pattern (a documented reference object, a query mapped onto it, the same object reused by anyone), not this code. Whether such a reference would change a LEGEND decision is SCI's question (ADV-162); I see no harness change that depends on it.

## 4. Independence of the source (conservative, as in RP-045)
The three authors of the NeuRoDev paper include **Zonca A and Davila-Velderrain J, who are co-authors of the Aqeilan laboratory's *Brain* 2026 paper** (Steinberg et al.; the registry and the held reading name them), and Davila-Velderrain J is also on the HUJI preprint of Abudiab 2025 about Wwox-null OPC cultures. Count NeuRoDev as **the same cluster as the Aqeilan programme** for any claim that uses it to support or test a result of that programme; it is independent only as a reference of normal development (no Wwox claim in it, per my reading of the deposit's descriptions, not of the paper).
