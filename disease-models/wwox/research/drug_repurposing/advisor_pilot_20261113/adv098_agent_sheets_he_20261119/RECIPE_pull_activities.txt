  from framework.adapters import chembl, _http
  fetch = _http.make_fetch("<cache dir>")
  out = chembl.query({"molecule": "<CHEMBL id>", "types": ["IC50", "Ki", "Kd", "EC50"], "max_rows": 3000}, fetch=fetch)

Checks before a number leaves a sheet (2026-11-25, after the row-by-row re-check in RECHECK_ROWWISE_HE_20261125.md; this is the template of a new sheet):
  1. Compute every fold, ratio, range or spread with a query over ALL held rows for that target, not over the rows in view; print those rows, quote the extremes, and group by document before writing "one document".
  2. A count says what it counts (rows, targets, targets with a measured value, documents), and is read from the same query.
  3. A row with relation ">" or "<" is a bound and is written as one.
  4. A blind verification packet carries the whole source table the number was computed from, not the one quoted row.
  5. recipe_tabulate_activities.txt matches expected gene symbols in upper case only: rat and mouse rows of the same gene land in "other targets". Match case-insensitively before calling a row another target.
  6. (2026-11-26, ADV-293 blind check; ADV rule) A title, a species, a tissue, a document id and a number in a sheet are pasted from the PubMed record or the held row, never retyped from memory and never completed in brackets: two abstract titles (one completed with invented words, one with the wrong species) and one tissue name were found wrong in the blind check of batches 4 and 5.
  7. (2026-11-26, ADV-293) A sentence with 'flips', 'order', 'only', 'every', 'the one' or 'not N' names the subunit, potential, document or row set it holds for; print every row of the other subunits and documents before writing it.
8. A sheet error named in a later note is repaired in the same edit: the sentence itself is changed in place and the note records the first-written text (batch 11 left a named misreading of a knockout phenotype in the sentence for six days; ADV-293 counted it as an error not repaired).
