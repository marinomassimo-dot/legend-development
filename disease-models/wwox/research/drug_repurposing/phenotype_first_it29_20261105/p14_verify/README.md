## 6. Answer-first sentences that over-claim or could be read as advice

1. "Non-selective HDAC inhibitors are signed against oligodendrocyte maturation" and "Its one finding that changes a carried decision": the evidence is genetic HDAC1+2/HDAC3 loss and one marker-level inhibitor result (Olig2 in purified precursors), partial full text, none with myelin, none tested for class IIa. It adds a limit; it does not change a decision (hand-overs and ranking are unchanged, as the same bullet says). Suggested: "adds a carried limit on 30 proposals".
2. "HDAC3 loss diverts precursors to astrocytes; HDAC3-directed inhibitors lowered Olig2" without the B11 catalytic-dead result (1a-i).
3. "216 rows over 191 families (137 consistent)" invites a reading as 137 supported levers. The README does qualify that 106 are glucocorticoid-receptor rows and that all signs are external; still, "consistent" means target action matches a sign from a non-WWOX system, at marker level for most rows (many from partial full text or abstract). It should say marker-level, non-WWOX, retrospective next to the headline count.
4. Case 2: "a never-considered class (serotonergic agents, fish evidence only)" and "demotes ethosuximide" read as ranking advice on drugs for a paediatric epilepsy; they rest on single laboratory zebrafish lines and a handful of rows. "Sodium-channel blockers would worsen an inhibition-loss lesion" is a clinically sensitive statement from fish and one mouse model; present only as a design logic for an in-vitro discriminating experiment.
5. "Right calls" table: the unit is a compound named in the same literature, retrospective; the README says so. Keep "7 right (5 independent of the signing study)" after the apicidin correction.
6. Nothing in the file recommends use of a compound; "No compound is qualified as a pro-myelinating lever" is appropriately restrictive.
