## A. Pracinostat HDAC5: do the assay descriptions in hand resolve the discordance?
No. ChEMBL holds only **two** pracinostat activities on HDAC5: IC50 5,113 nM (J Med Chem 2018, "HDAC5 (unknown origin) using fluorogenic HDAC class2a as substrate, 30 min, fluorescence") and Ki 21 nM (Bioorg Med Chem 2015, assay description "Inhibition of human HDAC5", nothing more). The 47 nM value is a Guide to Pharmacology record of the originator paper with a **blank** assay description. Substrate, preparation, format and isoform are therefore stated for **one of three** values (the class IIa substrate one, the weakest), and the three stay **not comparable**. The only new comparator on the same substrate class is TMP269 (below): 80 nM on HDAC5 in a Boc-Lys(TFA) assay, so under a class IIa substrate the compound class designed for class IIa is far more potent than pracinostat; that is a comparison across two papers, not a measurement of the pair. Reopening condition: the methods of PMID 20197387 and 25637120 (substrate and enzyme preparation).
