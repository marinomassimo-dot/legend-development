# IT29 P3-E: the compensatory-role problem in developmental epilepsy (Case 2, network hyperexcitability)

Scientist E, event-id suffix -06, 2026-11-05. Non-canonical research material, not medical advice; no dose, schedule or clinical preference is given. Public edition: the subject is the WWOX-DEE reference genotype class. Nothing outside this directory was edited; receipts are drafts for the Orchestrator (not recorded).

Sub-question: in which developmental epilepsy models has an intervention that lowers network activity been shown to harm a function (cognition, plasticity, circuit maturation, survival, interneuron development), or has the hyperexcitability been shown to be a compensatory response whose suppression worsens a deficit? Table: `evidence_it29_E.tsv` (42 rows, 22 papers plus one repository record). Convention in the table: for `DISCHARGE:` rows `favourable` = less discharge; for `FUNCTION:`, `FUNCTION-SAFETY:` and `COMPENSATION:` rows `favourable` = the functional or survival outcome is better and `adverse` = worse. Benefit on discharge and benefit on function are never merged; a source with one endpoint measured and the other not gets only the measured row, and a missing pair is said in the note (one explicit `undetermined` row marks the Scn1a clonazepam gap).

## 0. Decision (first)

1. **No source shows, in a developmental epilepsy model, that suppressing network discharge harmed a function because the hyperexcitability was compensatory.** I looked for it directly and did not find it. That is "not found", not "does not exist": compensation has been shown in the opposite form (hyperexcitability built by the network after a change in inhibition, row E35), never as "bursts counterbalance a deficit, so silencing them worsens it".
2. **What exists is a harm of generic suppression in the naive developing brain, independent of any compensation.** Benzodiazepines (diazepam, clonazepam), phenobarbital, phenytoin, valproate, vigabatrin and NMDAR blockade each trigger apoptosis in neonatal rat (Bittigau 2002; Ikonomidou 1999, abstract); phenobarbital delays hippocampal inhibitory maturation and impairs adult learning (Forcelli 2014, 2016, 2018). None of those studies has a seizure endpoint, so benefit on discharge cannot be paired with the harm. Exposure matters: a lower phenobarbital exposure with bumetanide did not raise apoptosis (Cleary 2013).
3. **There is a mechanistic route by which network silencing could cost a deficit-relevant function**: pyramidal-cell activity in P5-P8 keeps PV and SST interneurons alive, and chemogenetic dampening lowers their number (Wong 2018, E33 and E34). This was tested in normal development, not in an epilepsy model, and with a chemogenetic tool, not a drug. For Wwox neuron-deleted cortex (low Pvalb transcript, neonatal add-back window) this is the single most pertinent lead, stated as a hypothesis, not as a finding.
4. **Where both endpoints were measured after the same intervention in the same model, function followed discharge only when the intervention acted on the driver.** Rapamycin in the multiple-hit spasms model reduced spasms and partly rescued Barnes-maze learning (E29, E30), but cognitive benefit appeared without any change in other seizure types or interictal spikes (E32), and the same exposure worsened learning in healthy controls (E31): the benefit exists only where mTORC1 is pathologically high. A non-NKCC1 bumetanide derivative stopped asphyxia seizures and prevented hippocampal neurodegeneration (E14, E15; abstract only).
5. **Clinical anchors say the same thing in humans, without a compensation claim.** UKISS: better early spasm control with hormone treatment, no difference in development overall at 14 months or 4 years, subgroup advantage only without an identified aetiology (E39-E41). Repository CLAIM 031: two WWOX-null children stayed profoundly delayed despite improved epileptic activity (E42, record only). Seizure control and development are separable; this is evidence against "discharge as proxy for function", not for "silencing harms".
6. **GABA-A potentiation: repair when the lesion is hypoinhibition, harm when exposure is early, long or high.** Low-exposure clonazepam rescued social and fear-memory deficits in Scn1a+/- mice while on drug and the effect reversed on washout (E26, Han 2012); the benefit is bell-shaped and alpha1-preferring agents did the opposite in BTBR mice (E28). The same class is neurotoxic in naive pups (E16, E21-E23). The balance is set by exposure and age; for IT14 H1 (clobazam/NDMC) this keeps the question at probe level and favours short, graded, reversible exposure arms with a function read-out, not a seizure read-out alone.
7. **Bumetanide/NKCC1 is context-dependent and failed more often than it succeeded in vivo**: positive in slices and in a hypoxia model with phenobarbital (E1-E4), null alone and null in two further asphyxia experiments (E5, E11, E13), a stopped open-label trial with a hearing signal (E7, E8), and a small randomised pilot with a post hoc positive seizure result (E9, E10). It does not support a Wwox lever; the chloride state of Wwox neurons is unmeasured.
8. **Kv7, T-type, NMDAR, mTOR on both endpoints**: Kv7 opener: seizure benefit in a Kcnq2 mutant (E37, abstract), no learning deficit but some anxiety-like effect after neonatal exposure in naive rats (E24, E25); T-type: only one tolerability study found (E38, null, not a seizure model); NMDAR: apoptosis liability in naive neonates (E20); mTOR: both endpoints, with the homeostatic caveat (E29-E32). No agent class is separated by direction in a developmental model on both endpoints at once, except rapamycin.
9. **For repair versus counterbalance in Wwox (IT14 P3)**: nothing here moves the IT14 E0/E1 design; it adds a second axis to every drug arm, a function read-out (maturation of inhibition, interneuron number, a learning task) in addition to burst incidence, and a treated wild-type/heterozygote control arm, because the rapamycin and phenobarbital controls show that an agent can help a model and harm a normal circuit.
10. **Rows by direction**: favourable 13, adverse 13, null 9, context_dependent 5, undetermined 2 (42 rows). Most adverse rows are in naive animals.

## 1. Evidence by theme

### 1.1 Benefit on discharge without a paired function endpoint (NKCC1/bumetanide)
Dzhala 2005 and 2008 (abstracts) and Dzhala 2010 (partly read) give the mechanism: recurrent seizures load neurons with chloride, GABA-A potentiators lose efficacy as seizures recur, and bumetanide restores it in slices; bumetanide had no effect in NKCC1-knockout slices (target-controlled, E1). Cleary 2013 (partly read) reproduced it in a hypoxia model as an add-on and found bumetanide alone close to inert, and no rise in apoptosis at the lower exposure used (E4-E6). Independent asphyxia experiments (abstracts) found no potentiation of phenobarbital even at higher bumetanide exposure, while midazolam did suppress seizures after asphyxia (E11-E13). In the neonatal trials, discharge benefit was limited in the open-label study, which also recorded hearing impairment in survivors (E7-E8), and positive post hoc in the randomised pilot (E9-E10). None of the bumetanide sources measured cognition or maturation. Bumepamine, a derivative that does not inhibit NKCC1, did both: stopped seizures and prevented hippocampal neurodegeneration (E14-E15, abstract only), which separates "discharge and tissue protection" from the NKCC1 mechanism.

### 1.2 Harm of antiseizure exposure in the developing brain (no compensation involved)
Bittigau 2002 (read: methods, Table 1, abstract) measured degenerating-cell fraction in 16 regions of P7 rats; phenytoin, phenobarbital and valproate raised it in most regions (E18), and the abstract names diazepam, clonazepam and vigabatrin too (E16, E17); estradiol ameliorated it (E19). Forcelli 2018 shows a circuit consequence: no developmental rise in mIPSC frequency and persistent giant depolarising potentials after neonatal phenobarbital (E21); Forcelli 2014 and 2016 show adult learning deficits (E22, E23). Retigabine, tested in the same 2016 design, did not impair learning (E24) but raised anxiety-like behaviour in two of three tasks (E25). All are naive-brain studies; they establish liability, not cost in a diseased circuit.

### 1.3 Hyperexcitability as compensation, and activity as a developmental signal
Wong 2018 (partly read) establishes that interneuron survival depends on pyramidal-cell activity in a defined window and can be moved in both directions (E33, E34). Soh 2018 (partly read) shows excitatory drive onto pyramidal cells rising after interneuron Kcnq2/3 loss, which the authors call possible homeostatic compensation for increased GABAergic signalling, and shorter seizure latency in the Pvalb-Kcnq2 null (E35, E36); this is a knockout, not an inhibitor, and the direction of compensation is toward more excitation, so it makes the network look hyperexcitable as a result of a change in inhibition. For Wwox, where sIPSC amplitude is about half of control in the KO (IT14 P3), this is the compensatory logic IT14 left open: excess excitation could be built on top of an inhibitory loss and would be the part a potentiator corrects. No source tests that in a DEE.

### 1.4 Both endpoints in one model
Rapamycin (Raffo 2011, partly read): spasms down in a dose-related way, learning partly rescued, other seizures and interictal spikes unchanged, healthy controls worse (E29-E32). Bumepamine plus phenobarbital: seizures and hippocampal damage (E14-E15). UKISS and the 4-year follow-up: spasm control and development measured in the same infants (E39-E41). Scn1a+/- clonazepam: function only (E26-E27). Pressler and Soul: seizure burden and hearing (E7-E10).

### 1.5 Seizure control and developmental outcome in WWOX-DEE
CLAIM 031 is held as a record: Shaukat 2018 describes impairment preceding the epileptic encephalopathy and not improving with better control "in some of these cases", n=2, qualifier ambiguous. I did not re-read the primary. It supports that discharge control does not by itself rescue development; it does not address whether silencing harms (E42).

## 2. What is not established

* That any lowering of network activity in an epilepsy model worsened a deficit; the harm literature is in naive animals, mostly phenobarbital and mostly one laboratory.
* That bursts in the Wwox neuron-deleted network are compensatory; no source in this package measures it. The E0/E1 design of IT14 P3 is still the only discriminating route.
* Dose-, age- and duration-dependence of benzodiazepine harm: the sources mix single and repeated exposure, rat and mouse, and acute versus chronic.
* Any paired seizure-plus-cognition endpoint for a T-type blocker, an NMDAR antagonist or a Kv7 opener in a developmental epilepsy model.
* Genotype transfer: Scn1a, Kcnq2, Tsc/mTOR and hypoxia lesions differ from Wwox in cell type, locus and chloride state.

## 3. Not reached

* Full text for Dzhala 2005 and 2008, Pressler 2015, the asphyxia-model papers, UKISS 2005 and 2010, Ikonomidou 1999, the Kcnq2 R207W paper and the Ts65Dn paper: abstract only (no receipts written for them).
* The PubMed MCP tool returned an API error for every search; I used Europe PMC and NCBI E-utilities instead. One E-utilities search endpoint was intermittently unavailable.
* Bittigau 2002 and Dzhala 2010: the PMC XML was restricted, so I read the PMC HTML page text; I read Table 1 and methods for Bittigau and abstract plus targeted passages for Dzhala.
* Not searched in depth: Syngap1, Stxbp1, Cdkl5 and Scn2a models, ketogenic/steroid developmental-outcome studies, and the infantile-spasms vigabatrin early-treatment literature beyond UKISS. These would reopen the question if one had a seizure endpoint and a learning or maturation endpoint on the same drug.
