## 4 · What the survey settles for deliverable B

Six adapters are measured green at the dry-call level and need only the standard library:
Open Targets, ChEMBL, PubTator 3, openFDA (label + FAERS, DailyMed as the fallback), Orphadata,
iLINCS. Each is one plain Python file — a function taking a dict and returning a dict, plus a
self-test — discovered from its directory and deleted with nothing else to edit (operator
instruction of 2026-10-22: lean, no rigid contracts, no registry to keep in sync); each records
the API or data version it was measured against as a value in its output, not as a schema field;
each stamps retrieval date and query; none emits a score. Nothing in this note is a candidate, a
dose or a recommendation.
