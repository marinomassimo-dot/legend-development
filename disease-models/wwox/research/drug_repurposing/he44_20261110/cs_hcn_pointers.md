# HE44 H2 — pointers for the scientific work on the registry unit anomalies (no column is chosen here)

Source of the list: `registry_unit_flags.tsv` (HE43; GtoPdb 2026.3.1, input digest in the file). In each row the registry's log value and its own nanomolar column differ by a factor of 1000; the check does not say which column is wrong, and plausibility of one value is not a reason to choose it.
Rows that reach the IT41 search table (`search_rows.tsv`, columns `affinity`, `affinity_nM_column`, `affinity_check`): Cs+ on HCN1, HCN2 and HCN4 (S2, the Ih tool arm). Question for the primary paper (the registry row's reference is in the `pubmed_id` column of the flags file): which quantity and unit does the paper's table report for Cs+ at each HCN isoform, in which system and condition, and does a second isoform row (HCN3, not flagged) read the same way? Until read, a consumer uses neither column as a potency; it shows the original pair and the flag.
Other rows of the same kind, outside the IT41 table: diphosphoric acid and NE10790 on farnesyl diphosphate synthase, decavanadate on TRPM4, DkTx on TRPV1. Five further rows disagree by other factors (listed in the flags file as DISAGREE) and are left unexplained.
Limit kept in the test: DQP-1105 is a registry row whose two columns agree (AGREE) while the primary table differs by 1000; the internal check would not have found it, and it is not offered as if it would.
