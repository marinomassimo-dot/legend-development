# A distinct perampanel premise, frozen before opening the RNA reads

WWOX loss may increase calcium entry through AMPA receptors by increasing the fraction of mature GRIA2 RNA unedited at GluA2 Q607R. The rival explanations are loss of GluA2-containing receptors, altered synaptic input, and generic hyperexcitability with preserved editing. Perampanel blocks multiple AMPA receptor subtypes. A positive editing result would justify testing calcium-permeable AMPA currents and their response to perampanel. It would establish neither selective drug action nor modified disease progression.

Use all six human isogenic cerebral organoid libraries from GSE156243 (two WT and four KO, week 15). Sample identity, library size and published regional phenotypes were known when this prediction was set. No site counts have been opened. Use the Q607R codon and feature position 2135 of NM_000826.6 (CDS starts at nt 316, c.1820), with genomic CAG and edited CGG. The prose note also mentions nt 2279; in this version 2279 is in a GAA codon and does not encode Q607. Record and validate flanking sequence uniqueness in the human reference including the GRIA paralogs. Count reads from either strand using the same flanks for every allele. Require central Phred quality >=30 and flanking bases >=20 on the primary window (12 exact bases each side); separate other central bases as empirical error controls. Record independent sensitivity to a longer exact window (18 each side), site away from read ends, read-start diversity and, if coverage permits, spliced reads crossing the downstream splice junction with >=8 bases on each exon. Unspliced precursors, PCR duplication, alignment context and correlated organoid libraries are critical failure modes.

Report unedited A / (A+G) per library, assay coverage, error counts, and uncertainty. Compare unweighted means across libraries, with leave-one-library-out extremes; never treat reads as biological replicates. A shift worth prioritizing was defined for this screen as a KO increase of >=5 absolute percentage points, stable in sign after leaving out any library, with >=30 informative reads in every library and corroborating direction in splice-aware reads where >=10/library are available. Smaller shifts can still be real. If sparse, report the range consistent with the coverage, no cell-specific verdict. Effects on the amount of transcript, surface receptors, glial vulnerability or seizure control remain separate. A replicated bulk negative would narrow a biochemical mechanism while leaving GluA2-lacking channels open. An independent mouse cortical contrast is a second-stage check if raw data and species-specific reference mapping permit.
