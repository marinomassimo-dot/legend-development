# Human GRIA2 splice-junction test

23 November, SCI_CODEX. Locked before measuring any reads for this new question. In mouse neuronal-deletion cortex the modeled flip share among classifiable Gria2 transcripts was slightly lower in KO; the hippocampal coverage criterion failed. The human test is independent of the deposited mouse transcript estimates and uses the same six organoid libraries previously inspected for a different RNA-editing site.

Use the 3′ junction joining each human GRIA2 alternative cassette to the downstream exon. The 5′ side lies close to the distinct R/G editing region and is excluded. Select 31-base exact matches spanning the 3′ junction with 10–21 bases on each side, retaining the same usable offsets for flip and flop. Primary is centered (15 cassette bases plus 16 downstream bases) if available, secondary uses any verified balanced offset. Use curated human RefSeq exon coordinates and translated motifs, require no exact hit on either genomic strand in hg38, matching human Ensembl cDNAs only for GRIA2, and no opposite class among curated cDNAs. Count a read once per rule in either orientation, separately record conflicting assignments. Require Phred >=20 for all 31 bases and give a Q30 sensitivity. Validate file digest, compressed bytes and read count for every run. Report library-level fractions; require at least 20 informative primary reads in each of the six libraries, no mixed class counted and stable effect sign under omission before interpreting direction. Apply the same +/- five percentage-point threshold as the mouse study. Limited depth yields a measurement-bound result. Reads are not genotype replicates. The two WT and four KO libraries come from the original study; independent genetic backgrounds are required for broader inference.
