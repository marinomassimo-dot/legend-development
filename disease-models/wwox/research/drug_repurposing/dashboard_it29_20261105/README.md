# IT29 P13: functional check of the shareable pages

`view_functional_it29.py <package dir>` drives the five language pages (en, it, fr, es, de) in headless Chromium through the existing `Cdp` client and checks: language links resolve and the current page is marked; the `html lang` attribute; every in-page `#id` link reaches an element; the ranking filter (the page's own `n of m` counter: search with no match gives 0, reset restores, a select filter narrows); `#compare=A,B` renders a comparison; external evidence links are well formed; and the five epistemic labels (unknown, not measured, unresolved, not applicable, opposed to the intended direction) are translated, pairwise distinct and mostly present on the page.

Result 2026-11-05 on the regenerated package: **60 of 60 checks pass** (12 per language). What it does not check: the correctness of the translated sentences beyond the five labels (the translation consistency check in `repurposing_view.py i18n --what check` covers placeholders and numbers), the served site (a separate check after the push), and the full set of filters. A first version of the search check failed because it counted table rows instead of reading the page's counter; the test was corrected to the page's own semantics, not loosened.
