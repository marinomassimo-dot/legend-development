# H-B1, the two-stage burst, as a hypotheses_only package (IT, 2026-11-16; non-canonical; not medical advice)

Written for: the consumers of `hypothesis_package.py` (the dashboard and the conditional proposals) and ADV. Reference genotype class only; class labels; no dose, no recommendation. `output/hypotheses.tsv` holds one row, HB1, in the layout of the INV-05 hypotheses packages with the optional `sign` cell set to `unknown` (the hypothesis assigns a trigger role to one class and a sustainer role to another; it asserts no aggravation and no match for any class). Origin: the memory-free arm of the 2026-11-16 round (`it_leap_baseline_arm_20261116/hypotheses_baseline_arm.md`, block H-B1), sole survivor of its judge run and called borderline-novel by that judge; held-data pre-test by SCI: not rejected, not supported (readout exists, the two decisive arms are not in held data). It joins INV-05 (manifest row) and changes no card, ranking or need.
