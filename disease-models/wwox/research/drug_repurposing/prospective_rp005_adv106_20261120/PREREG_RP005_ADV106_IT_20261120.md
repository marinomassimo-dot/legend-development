# RP-005 / ADV-106: first prospective test of the generation step on an unread full text (IT, 2026-11-20; hypothesis level; no dose, no recommendation; reference genotype class only; not medical advice)

**Frozen BEFORE anyone opens the target text.** This file, the slot list, the baseline rules and the input manifest are committed first; the generator's predictions are committed second (`PREDICTIONS_FROZEN_*.md`); only then is SCI asked to read the target.

## 1. Target and why it was chosen
* **Text:** Uebele et al. 2009, J Clin Invest, TTA-A2 in rodents (PMID 19451696; PMC copy PMC2689113, found by the PubMed ID-conversion tool, metadata only; the page was NOT opened). **No receipt** (`fulltext_receipts.py status --pmid 19451696` returns `[]`), no copy in `files/fulltext`; only the abstract has been read in this repository (HE batch 11, SCI v3.1 6.15, IT). Nobody has read the body.
* **Decision it bears on:** the class-level harm and confounder readout of the bridge pilot (v3.1 6.15: body weight, core temperature, glucose in failure-to-thrive null pups), and in particular how the core-temperature readout is designed (which animals, which control, what time course). The body's results (what was measured, when, in which animals, against which control, whether the Cav3.1-null mice carry the effect) are not in the repository.
* **What IT knows (the contamination I declare):** the abstract: TTA-A2 acutely increased sleep, lowered core body temperature, prevented diet-induced weight gain in normal-weight animals and reduced body weight and fat mass in obese rodents; Cav3.1-null mice resist diet-induced weight gain. The generator and the baseline get the same abstract-level facts and nothing from the body.
* **Not chosen:** the WWOX clinical series (no plain-client access, SCI ADV-086: no decision could move).

## 3. Scoring rules (written now)
SCI, blind to which prediction set came from which source (two anonymous sets, order randomised by a seed written in the sealed assignment file), reads the full text and scores each slot of each set: **HIT** (option matches the text), **MISS** (a different option), **NOT DETERMINABLE** (the text does not give it, or only in a figure that cannot be read); every score with a quoted sentence and its locator. A slot scored NOT DETERMINABLE is excluded from that set's denominator. S2 is a HIT only if both (i) and (ii) match. Both sets are scored on the same slots; ties are reported as ties.

## 4. The two predictors
* **Baseline (a trivial rule, committed in section 5 before the generator ran):** the typical target-validation pattern: S1 = B; S2 = ABOLISHED for (i) and (ii); S3 = REDUCED; S4 = ALL ADULT; S5 = REPEATED, MAINTAINED.
* **Generator:** a fresh blind delegate (model sonnet, effort high, stated back), one pass, receiving ONLY the files in `INPUTS_MANIFEST.tsv` (sha256 listed) and the slot list; forbidden: PubMed tools, web fetch, any search, any file outside the manifest; asked to report every tool it used. It fills each slot, with a one-sentence reason citing a manifest file, and a confidence (low, medium, high). The repository's own generation engine (`run_generation_it21.py`) emits compound proposals, not predictions about a paper's content, so it is NOT the generator here; the generator is the repository's evidence as a reader sees it (cards, sheets, notes), which is the only form in which the generation step's inputs exist for this question.

## 5. Baseline predictions (frozen with this file)
S1 B; S2 (i) ABOLISHED, (ii) ABOLISHED; S3 REDUCED; S4 ALL ADULT; S5 REPEATED, MAINTAINED.

## 6. What the result decides (RP-005)
Report: hit rate of each set over determinable slots, direction of the misses, whether the generator beat the baseline (strictly more hits), and one of **keep / revise / remove** for RP-005 with its cost (delegate tokens, my hours). With five slots and one text the result is a pilot, not a statistic: a margin of one slot is not evidence. A miss is a result.
