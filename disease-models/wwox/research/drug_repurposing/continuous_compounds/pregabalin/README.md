**Discriminating prediction.** In the same age-matched neuronal preparation and with measured free pregabalin, distinguish CaV2.1- and CaV2.2-associated changes in calcium entry and directly measured release before versus after changes in surface calcium-channel abundance. Measure pyramidal and inhibitory pathways separately. A shift in gating or calcium–release coupling before surface abundance changes supports an acute branch. A later change in terminal abundance with the acute readout intact supports altered trafficking. In each branch, use an α₂δ-1 versus α₂δ-2 perturbation whose baseline trafficking, calcium influx and recruitment are independently matched or modeled. A binding-deficient construct with a trafficking deficit at baseline would not identify drug specificity by itself. Prefer an effect on late recurrent excitation with preserved first recruitment and native inhibition. A reduction of inhibitory release or equal depression in both genotypes lowers the case for a WWOX-selective correction.
