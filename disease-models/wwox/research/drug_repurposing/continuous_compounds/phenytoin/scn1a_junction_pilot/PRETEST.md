# SCN1A 5A/5N diagnostic coverage pretest

Use the first previously documented control run SRR12453541 chosen for its lowest compressed size among the six intact published libraries. The primary analyzable event is a 31-base exact exon 4-to-exon 5 junction, with 10–21 bases on each side. Retain offsets only when both exon sequences distinguish A versus N and have no matches in the reference genome or any other Ensembl gene's annotated transcript. Verify strand, full-locus exon endpoints, opposite isoform specificity, quality Q20/Q30 and compressed file integrity. The same rule and offsets apply to both alternatives. Count all published reads in the selected run, one read once per isoform, expose ambiguous crosses and keep the centered rule primary. Aim for at least 20 informative reads before considering equivalent analysis of several biological libraries. This is coverage feasibility, with no genotype inference. Mouse Scn1a provides a general inhibitory reference since it lacks the functional human 5N equivalent in Liang Fig. 4A. Do not transfer a direct human exon pharmacology claim to mouse.
