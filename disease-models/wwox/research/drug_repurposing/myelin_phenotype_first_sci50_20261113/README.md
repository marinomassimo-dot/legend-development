## Answer first

**There is one conditional possibility to put to the test and one that must wait, and the generative gain is smaller than the first draft claimed.** Frame fixed before searching (`S0_before_search.md`): a seizure-free neuron–OPC co-culture, sheath formation and structure as the endpoint, four levels kept apart; one producer, one blind verifier (own strings; a narrow recheck), corrections applied by the producer and by `output/apply_v13_recheck.py`.

1. **What can be put to the test first (H4, conditional):** *Wwox-null neurons release a factor that lowers OPC maturation* (IPOTESI; **no row links Wwox to any secreted product**). It needs only OPC monoculture, one neuron-genotype factor and **no** resolution of the muscarinic/sterol question. It is **not a new test for LEGEND**: conditioned medium from wild-type versus null neurons is already INV-06 X1 arms (b) and (c). What is new is a **candidate mechanism** from neuron-specific Tsc models (neuron-secreted CTGF, an authors' in vitro claim, read at targeted depth; neuronal CTGF loss restores the share of myelinated axons but not myelin thickness) and the **controls the arm lacked**: a fresh-medium baseline and a mixing arm (a missing cue versus an inhibitor), neuron purity (non-neuronal DRG cells carry the null genotype too), a dilution series, the B27/T3 caveat, a positive control (recombinant or HEK-derived CTGF; Tsc2-knockdown neuron medium), and a detection limit from the monoculture's own variance (not the 20-point threshold borrowed from the co-culture).
2. **What must wait for a gate (H1, conditional):** *the neuron sets a ceiling on sheath structure that an OPC-intrinsic enhancer does not lift.* The design is a **reagent pair crossed with neuron genotype**: an **M1-selective** arm (PIPE-307, a reagent absent from LEGEND), an **EBP inhibitor without M1 affinity**, with genotype as a factor, the reverse pairing in the first block, a dose-response with a monoculture ceiling, and the marker level read beside sheath structure. It is interpretable only after **gate 0**: T3 and T4 measured in the complete medium (INV-12 step 0), the null-neuron deficit **reproduced blind** with independent preparations and axon-density denominators (the published result is two experiments, n = 4 v 4, peripheral DRG neurons, MBP morphology classes), and the OPC window checked (acetylcholine inhibits differentiation with IC50 about 58 nM, so an M1 antagonist needs tone; PIPE-307's EBP activity is untested). The first draft's Chrm1-null control is **not interpretable as written** (the null baseline is already about five-fold elevated, the size of the drug effect, so loss of the drug effect is expected under either route): contrasts in null cells are read only when positive.
3. **What was abandoned.** **H2** (a supply limit separable by a lipid arm): no neuron-side datum, and a high-fat diet gave no rescue in the Camargo double mutant; kept as a note (L2-NOTE) with no verified dish reagent. **H3** (more but shorter sheaths): contradicted by the neonatal clemastine re-read (node number fell, internode length tended to increase non-significantly, the authors attribute the effect to microglia). **The Chrm1-null control**, as above. The producer's first headline, "no source treats a neuron-driven hypomyelination with a compound at sheath or conduction level", was **false as worded** (rapamycin and RAD001 in neuron-specific Tsc1 knockouts improved myelination markers, no conduction readout; Meikle 2008 is already held as batch_sci_20261105 R50); it survives only as: *within the strings run, no OPC-intrinsic enhancer was found assessed at sheath structure and conduction together in an isolated neuron-driven model.* Tcf4 (clemastine, sobetirome; EM and callosal N1/N2) is a **global heterozygous** allele and J4 a **global Tsc2 heterozygous** (mixed) model: neither is a neuron-driven model.
4. **The premise behind the pair is real and unresolved.** The muscarinic (M1) and sterol (EBP) readings of clemastine and benztropine disagree in the sources read; no source opened tests both on one OPC preparation (a Europe PMC M1 + EBP string returned zero hits); LEGEND already records this as unresolved (IT29), so the pair is **a design change, not a new observation**.
