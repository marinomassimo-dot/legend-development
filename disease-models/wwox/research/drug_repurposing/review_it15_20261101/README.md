M2. INTERPRETABLE is granted to a comparison its own README says is not comparable. scout_it14_p6_20261101/selectivity_same_document.tsv, apinocaltamide chembl:CHEMBL4177680#CACNA (Cav1.2 2,410 nM against Cav3.x, ratio 377) is INTERPRETABLE although the stimulus differs (CaCl2 re-addition versus KCl; assay CHEMBL4181722) and origin is "unknown"; the grade docstring requires "assay formats known and compatible". selectivity_p6.py techniques() only tests a hand list of nouns (TECH, line 17) and any single shared token passes ("flux", "binding", "enzyme" are weak). test_informative_same_system_pair_is_interpretable uses identical descriptions for both assays, so it cannot catch this. Replacement: add a stimulus/agonist/voltage token comparison (extract "KCl", "CaCl2", "glycine", "-40 mV" etc. from description) and add "stimulus differs" to limits; the Cav row becomes LIMITED with the ratio kept; add a test with the real two descriptions.

M3. A bare ratio is still shown for non-comparable groups, contradicting the README. drug_repurposing/README.md (IT15 P2 paragraph) says the grader "no longer computes a ratio for groups that are not comparable". selectivity_p6.py emit() (line ~172) computes a ratio for every LIMITED group. Real cases: apinocaltamide #CYP (ratio 3.71, reason "assay techniques differ", an inter-isoform liability spread, not target selectivity); d-AP5 CHEMBL4024770 53.8 and bumetanide 487 with "assay context not retained". Replacement: suppress the ratio (ratio_not_computed_because = reason) when limits contain "techniques differ", "cell systems differ" or the family is a liability family (CYP, ABC, SLC off-target); or reword the README to "a ratio is shown for LIMITED groups next to its limiting reason, and is not a selectivity claim".

M4. family() takes only the leading letters (line 21): SLC1A2 and SLC12A5, or any two SLC/CYP genes, count as one family; INTERPRETABLE can therefore join unrelated transporters or enzymes. No such INTERPRETABLE row exists in the committed 42-row table, but the 496 INTERPRETABLE groups in target_first_it15_qa_nmdar_20261101/graded_comparisons_qa.tsv (47 percent of groups) were not individually checkable here. Replacement: family = letters plus the first digit run for SLC/CYP/KCN-type prefixes, or an explicit family table.
