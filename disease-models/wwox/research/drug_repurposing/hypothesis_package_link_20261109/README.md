# Physiological hypotheses and experiment matrices reach the consumer (Harness, 2026-11-09)

Not medical advice; no dose, schedule or route; reference genotype class only. Nothing here is a claim, a rank or a gene arc.

## The change

* `framework/scripts/hypothesis_package.py` reads a package folder in place (hypotheses, alternatives, experiments, prediction matrix, observations) and returns, per investigation, each linked hypothesis with its rows verbatim. No copy exists.
* One committed file per package, `consumer_links.tsv`, states the only interpretive step: hypothesis id, need id, investigation id, card ids, `link_state`. `check` validates it against `needs.json`, the investigations table and the cards. `CARRIED_IN_TEXT` must name a literal substring that is really in the investigation cell, or validation fails.
* Rivals, experiments, arms and matrix columns are reached by literal ids found in the cells. An id-shaped token that matches nothing is listed as unresolved, never guessed. Matrix columns `H1..H7` are the producer's labels and are not mapped to alternative ids.

## Call point for IT40

```python
import hypothesis_package as hp          # framework/scripts/
rec = hp.record_for(hp.load_all(), "INV-05")   # {inv_id, state: LINKED|UNLINKED, hypotheses: [...]}
```

Each hypothesis record has `kind` (`physiological_hypothesis`), `gene_arc` (always `False`), `need_id`, `card_ids`, `link_state`, the verbatim hypothesis row, `alternatives`, `other_hypotheses_cited`, `matrix_columns_cited`, `arms_cited`, `experiments` (each with its arm rows and `unresolved_refs`), `experiment_state` (`STATED` or `NO_EXPERIMENT`) and `unresolved_refs`. Command line: `python3 framework/scripts/hypothesis_package.py show --inv INV-05` and `check`.

## IT41 update (2026-11-09, Harness): explicit packages, row references, matrix_column, two kinds of record

What changed in `framework/scripts/hypothesis_package.py` (calls `load_all()` and `record_for(pkgs, inv)` keep their shape; `unresolved_refs` stays a list):

* **Explicit selection.** `load_all()` reads only the folders named in `disease-models/wwox/research/drug_repurposing/hypothesis_packages.tsv` (package, dir, role, inv_id, why). `check` validates the manifest and prints `INFO not in manifest, not read` for package-looking folders that are not listed (aed_compare_it31, gsk3_eif2b, hcn, nrf2_inv08 today). Adding a package is one reviewed row; a folder that merely exists is not an authorised input.
* **Two kinds, never one object.** `record_for` carries `physiological_hypotheses` (hypotheses, alternatives, experiments, matrix). `comparison_for(pkgs, inv_id)` carries `pharmacological_comparison` rows (`comparison.tsv`, joined to `new_measurements.tsv` by the key before " (" and to `decisive.tsv` by D-ids). A measurement whose `blocks_which_comparison_row` reads "all rows" reaches every key; a block on no key is refused by `check`. The comparison rows keep their qualifier cells (`compound_or_probe_qualified_or_identity_unresolved`, `outcome_*`) verbatim and `gene_arc` is False.
* **Row references.** Every row used is listed in `source_refs` as repo-relative `file:line` (the line where the row starts; a test reopens the file and compares the first cell).
* **`matrix_column` is consumed.** An alternative that writes a column header in `alternatives.tsv` is validated against the matrix header (a wrong one is an error, a blank stays unmapped). The record then (a) lists, in `alternatives_via_matrix_column`, the alternatives that declare a column the hypothesis cites, and (b) returns `expected_results` per experiment arm and column with the producer's `prediction_label` (INFERENZA stays INFERENZA). The IT40 data that writes the column is on `task/it40` (560601df), not on main at this commit; the path is proven on a synthetic package in `test_hypothesis_package.py` and must be run on the real data once IT40 lands (`python3 framework/scripts/hypothesis_package.py show --inv INV-05` should then show BH1 reaching AB01-AB04 by column).
* **Unresolved tokens, classified by rule.** `ref_classes` gives each token one of `AGE` (P13), `CARD_ID` (a card file with that prefix), `PROBE_NAME` (named in the package's probes.tsv), `BROKEN_REFERENCE` (the id family exists, that number does not), `UNCLASSIFIED`. Only `BROKEN_REFERENCE` is a defect (printed as WARN by `check`); on the committed packages there is none. No rule reads meaning.

State names, kept apart on purpose: `CARRIED_IN_TEXT` means a checked substring is *named* in an investigation cell; `STATED` / `NO_EXPERIMENT` mean an experiment row exists or does not; none of them says the output was *consumed*. Consumption is shown only by the output of the path that calls `record_for` / `comparison_for` (for IT40: `generation_it40_20261109/conditional_proposals.py`, for IT41: its comparison script).

Before and after on the committed INV-05 data: before, `record_for` returned the three hypotheses and no comparison; the nmda_composition_discrim comparison (5 rows, 12 measurements, 12 decisive propositions) was invisible to it. After, `comparison_for(pkgs, "INV-05")` returns the 5 rows with their measurements and decisive propositions (for example H_GluN2B: M-N1 to M-N4, M-N7 to M-N11, D04, D07, D09) and `source_refs` such as `.../nmda_composition_discrim_20261109/output/comparison.tsv:3`. This is availability, not a change of any ranking or of a prediction.
