# Physiological hypotheses and experiment matrices reach the consumer (Harness, 2026-11-09)

Not medical advice; no dose, schedule or route; reference genotype class only. Nothing here is a claim, a rank or a gene arc.

## The change

* `framework/scripts/hypothesis_package.py` reads a package folder in place (hypotheses, alternatives, experiments, prediction matrix, observations) and returns, per investigation, each linked hypothesis with its rows verbatim. No copy exists.
* One committed file per package, `consumer_links.tsv`, states the only interpretive step: hypothesis id, need id, investigation id, card ids, `link_state`. `check` validates it against `needs.json`, the investigations table and the cards. `CARRIED_IN_TEXT` must name a literal substring that is really in the investigation cell, or validation fails.
* Rivals, experiments, arms and matrix columns are reached by literal ids found in the cells. An id-shaped token that matches nothing is listed as unresolved, never guessed. Matrix columns `H1..H7` are the producer's labels and are not mapped to alternative ids.

## Call point for IT40

```python
import hypothesis_package as hp          # framework/scripts/
rec = hp.record_for(hp.load_all(), "INV-05")   # {inv_id, state: LINKED|UNLINKED, hypotheses: [...]}
```

Each hypothesis record has `kind` (`physiological_hypothesis`), `gene_arc` (always `False`), `need_id`, `card_ids`, `link_state`, the verbatim hypothesis row, `alternatives`, `other_hypotheses_cited`, `matrix_columns_cited`, `arms_cited`, `experiments` (each with its arm rows and `unresolved_refs`), `experiment_state` (`STATED` or `NO_EXPERIMENT`) and `unresolved_refs`. Command line: `python3 framework/scripts/hypothesis_package.py show --inv INV-05` and `check`.

## Before and after

`before_after.txt` (generated by the call above). Before: INV-05 reaches a consumer as two free-text cells of 440 and 376 characters. After: three hypotheses with need, cards, per-experiment arm rows (M01 to M18 with their `prediction_label`), rivals and unresolved references. INV-18 gives three hypotheses with alternatives A04 to A10. INV-01 gives `UNLINKED`, which states only that no package speaks to it.

## Checks the format claims against the code

* Their statement that MH2 and the matched-current form of BH2 are already carried is now mechanical: `intervention` of INV-18 contains "Ih (HCN) channel blockers"; `next_test` of INV-05 contains "d-APV" and "GluN2B NAM". Presence of the words shows the arm is named, not that its decision rule is carried.
* `bridges.tsv` and `probe_links.tsv` are untouched; the limits the producers gave for them stand.

## Limits and residual for IT40

* BH1 cites no alternative id in any cell; its rivals appear only as matrix columns. Linking `AB01..AB15` to `H1..H7` is a scientific reading (labels are close but not identical). The reader leaves it unresolved. A `matrix_column` cell in `alternatives.tsv`, written and verified by the producer or Orchestrator, would make it exact.
* The unresolved list includes compound, age and figure tokens (Z944, P13, S1); it is an honest residual, not a defect list.
* The recording-condition covariates and the number disagreements listed in the producers' engine_consumption files stay in `limits` text; this change does not give them structured fields.
* Delivery is available; no consumer calls it yet. The view, the generator and `needs.json` are Orchestrator's and were not touched.
