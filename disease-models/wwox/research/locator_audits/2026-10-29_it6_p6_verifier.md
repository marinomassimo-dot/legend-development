## 4. Next-experiment design (R1 to R7)

What discriminates:
- Boost versus repair is separated by the ruler: protein rises but binding ratio and phenotype stay below the wild-type curve (R3) versus fall on it (R2). This is the strongest part of the design, and it correctly keeps wild type as a ruler with five induction levels, since the wild type also rises (CBS 7.7-fold).
- Transcript effect is separated by mRNA per well plus a promoter reporter (R5). R7 (null line/empty control) separates non-WWOX effects.
- Pellet versus soluble separates the ASPA pattern (R4).

Gaps that weaken the discrimination:
1. R5 as written ("rises equally for wild type and mRNA tracks it") covers a transcript effect, but a wild-type rise with flat mRNA, the CBS result, is a post-translational boost of whatever is made and has no row. It would be read as R2 only if the variant lands on the wild-type curve, otherwise it falls between R2 and R3. Add an explicit row: variant and wild type rise by comparable folds, mRNA flat, function per molecule unchanged: boost, no repair; the question moves to the residual-function bound R, not to A02.
2. Translation-rate effects are not separated. Proteasome inhibitors induce stress responses that change translation; mRNA-flat plus pulse-chase half-life partially covers this, but a nascent-labelling column (synthesis rate) is needed to call a rise "stabilisation". The design already has pulse-chase, so the repair is a column, not a new arm.
3. Several outcome rows depend on an unvalidated function ruler (P5 section 4, unverified in the producer's own words). Until it exists, only L0/L1 can be read; the README says so. The R2 phrase "the word recovery is allowed at L4" should be conditional on the ruler's validation, not merely its existence.
4. R1 requires "mass spectrometry negative" without a stated floor; R1 would then read as "never made" for a floor above the true level. P8 already flags the unquantified floor; the floor should be a fixed column.
5. R7 as written ("effect in the null line") is ambiguous: a null line has nothing to detect unless it carries the transgene. Specify the null line plus empty vector.
6. Toxicity confounds: effective proteasome-inhibitor doses damage cells (HEK paper). The design includes viability per arm and a prior toxicity titration; the outcome rules should say that a protein gain only at a viability-failing level is excluded, not read as R2 to R6.
7. A refolding or chaperone arm is named only as "the next question" after R3. Because R3 is a plausible outcome and the CBS data show allele-dependent chaperone effects (I278T no, R125Q yes), including one HSP70/HSF1 arm now would let R3 and a refolding-sufficient outcome be told apart in the same run.
