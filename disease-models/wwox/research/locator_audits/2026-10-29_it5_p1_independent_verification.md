## Judgement of the producer's classes
- Coherent overall. NC/ND/unknown/publisher-table items -> C is correctly conservative. BY-SA items split into separate files (B) is coherent; keeping ChEMBL (BY-SA 3.0), GtoPdb (ODbL+BY-SA 4.0) and ClinPGx (BY-SA 4.0) apart is right (BY-SA 3.0 is not one-way compatible with 4.0 as incoming; I did not read the CC legal code, so the "4(b)" citation is unchecked).
- NCI caution (counts-only until read at NCI): justified, not too strict. The only licence evidence is DGIdb's own label plus a generic NCI-products text policy that does not mention the dataset, and the dataset page is gone. A defensible lighter option is class A with attribution "National Cancer Institute" on the strength of the copyright-reuse page, but that is an inference about what the page covers; I would not call the producer wrong.
- Class A sources with omitted conditions: (1) DoCM, CC BY 4.0 -> BY requires attribution, a licence link and indicating changes; README lists "indicate changes" only for MATRIX. Minor. (2) FDA: "unless otherwise noted" qualifier is dropped in the class table (the README row does keep it). Minor. (3) CIViC CC0 and HGNC CC0 -> no conditions; HGNC "recommends attribution" is stated. (4) UniChem: the terms say third-party rights may attach to the original data; class A for id pairs is fine, as the producer limits to identifiers. (5) MATRIX: see D3.

## Defects
- D1 (low) Producer's UniChem pointer is "UniChem docs point to EMBL-EBI Terms of Use"; the unichem termsOfUse URL is 404 today, the text is found on ebi.ac.uk/about/terms-of-use. Wording supported, URL path should be given.
- D2 (low) "verified at the content's own source" for DoCM: the source is an archived about-page in the project's GitHub history (live docm.info redirects to GitHub). Say "archived project source". Producer also states DGIdb's xlsx manifest lists DoCM as "no public dataset license identified" and the DGIdb 5.0 paper says "44 sources with varying content licenses": I did not read either (xlsx not opened, paper not fetched): UNVERIFIED by me.
- D3 (medium, inconsistency) The README says a container licence does not clarify the content's (DoCM/DGIdb argument), yet MATRIX is class A on the strength of a HF card licence field alone, although the rows carry ATC codes, DrugBank ids and ChEBI ids from third parties (ATC is WHO-controlled; DrugBank is non-commercial per DGIdb). The card's CC BY 4.0 cannot grant rights in upstream content. Suggest: class A only for fields MATRIX authors own (approval flags, names), identifiers-only for the rest, or read the card prose/upstream terms.
- D4 (low) "Verified" wording for NCI is correctly withheld. For PharmGKB/ClinPGx the producer says "partly"; I confirm only DGIdb's string (CC BY-SA 4.0, link clinpgx.org/page/dataUsagePolicy); I did not read the policy page either. Class B stays fine.
- D5 (low) Version-for-version claim that the 2024-06 importer (commit a35759a) has the same strings as live is unverified by me; the live API strings all match the producer's table.
- No missed claim_source among the catalogue's DGIdb rows. Not checked: Open Targets, DailyMed, ClinicalTrials.gov, PubMed/PubTator, DSLD (outside the assigned list).
