- **Used:** intake triage, retraction gate, full-text acquisition (figures + supplement),
  deep dive, discovery, group assessment, corpus cross-query, self-evaluation.
- **Declined with reasons persisted in the manifest:** batch sweep and priority matrix (one
  record, not a batch), hypothesis forge (no therapeutic candidate exists here and forging one
  would manufacture it), safety triage (no molecule), ASO designer (no splice content),
  BATCH_COMMIT (threshold not met and the operator excluded the canonical files).
- **Friction observed:** the PMC `bin/` route for the supplement returned a JavaScript
  interstitial and the Frontiers datasheet API returned 500; the Europe PMC
  `supplementaryFiles` endpoint returned everything in one request. A sequential Europe PMC
  search loop was rate-limited and needed pacing. None of this reached the analysis.
- **Micro-upgrades shipped (capability, not knowledge):**
  `CUTPOINT_ENDPOINT_DRIFT_GATE` — a data-derived cutpoint re-optimised per endpoint makes
  "high" a different set of patients in every column, so a marker significant for one endpoint
  and not another is not an endpoint difference; and no effect size is quotable without its
  group `n`. `RANK_OVERRIDE_SELECTION_GATE` — when a ranking is run and the entity carried
  forward is not the one it ranked first, record the override criterion and check whether it is
  the hypothesis under test. Both carry the measured instance that generated them.
- **Residual risk:** `DL-MECH-069` rests on an interaction reported by a paper LEGEND has never
  read (`FT-038`). It is written as a control to install rather than a mechanism to believe,
  which is the honest level, but the debt is real and declared.
