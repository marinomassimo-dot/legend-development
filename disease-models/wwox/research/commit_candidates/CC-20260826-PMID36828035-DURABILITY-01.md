## 2. 🔴 The verifiability defect, and the exact command that fixes it

The evidence object is durable. **It is not auditable from the worktree it lives in.**

```
$ python3 framework/scripts/locator_audit.py --pmid 36828035
    36828035  schema=2  — declares 1 text surface(s) that are absent from this tree
                          (files/fulltext/PMID36828035_Hussain2023_PMC.xml)
0 manifest(s) audited, 1 unauditable, 0 quote(s) not found
NOTHING AUDITED — a corpus that cannot be read is not a corpus with no defects
```

**Cause, measured — not inferred:**

```bash
git ls-files files/ | wc -l     # → 0
grep -n '^files/' .gitignore    # → line 7
```

`files/` is gitignored and therefore **per-working-directory**. The full-text corpus lives in the
main checkout; this worktree's `files/fulltext` holds a different, smaller set and does **not**
contain `PMID36828035_Hussain2023_PMC.xml`. The manifest that cites it *is* tracked and travels
with the branch; the artefact it cites does not travel at all.

⚠️ **The tool's own message is correct** — *"fetch them, this is not a defect in the reading"*. The
defect is not in the reading and not in the manifest. It is that **nobody had written down which
root to resolve against**, so the audit had never been run to completion on this manifest.

### The command that runs it — and its result

```bash
python3 framework/scripts/locator_audit.py --pmid 36828035 \
  --corpus <REPO_ROOT>/files/fulltext
```

```
    36828035  schema=2  17/17 text matched, 9 image  [OK]  PMID36828035_Hussain2023_PMC.xml
1 manifest(s) audited, 0 unauditable, 0 quote(s) not found
```

✅ **All 17 text locators match their artefact character-for-character.** The 9 pixel-anchored
locators are counted, not matched — an image locator cannot be string-matched, and the tool says
so rather than pretending otherwise.

🔴 **The `--corpus` path above is machine-specific and must not be copied into a canonical file as
written.** The transferable rule is: *resolve `--corpus` against whichever checkout holds
`files/fulltext`; the sha256 is the durable identifier, the path is not.*
