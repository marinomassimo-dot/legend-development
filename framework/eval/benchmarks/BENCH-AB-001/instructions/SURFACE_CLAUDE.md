# CLAUDE.md — benchmark surface router

This directory is **not** the LEGEND repository. It is a benchmark input surface: a fixed,
allowlisted set of files, identical to the one the other reader received except for two
declared files, prepared so that a first reading can be blind by construction rather than by
promise.

> **Every path below is relative to THIS directory**, and is written as a plain path rather than
> a link on purpose: in the repository where this file is authored the same paths mean something
> else, and a link that resolves in one place and silently misleads in the other is worse than
> no link. In the surface they are exactly where the files are.

**Read, in this order, before anything else:**

1. `ASSIGNMENT.md` — who you are here, what task, which mode
2. `benchmark/BENCHMARK_INSTRUCTIONS.md` — the common contract
3. `benchmark/MODE_DIRECTIVE.md` — your mode, and only yours
4. `benchmark/OUTPUT_SCHEMA.md` — the shape of what you produce

The discipline that binds you is in this surface and is the same text the repository carries:

```
roles/scientist.md
framework/protocols/scientist_reading_modes.md
framework/master/gold_is_in_the_details.md
framework/instruction/epistemic_discipline.md
framework/protocols/fulltext_read_receipt.md
framework/eval/failure_taxonomy.md
```

**Nothing here is medical advice**, and a benchmark does not change that.

> 🔴 **Stay inside this directory.** Every file you need is here; nothing you need is elsewhere.
> Reading LEGEND's own prior work on this paper — from any checkout, by any path — defeats the
> one property this surface exists to have, and every locator you record must resolve to a file
> inside this surface. If you believe something essential is missing, **say so and stop**: a
> missing input is a finding about the benchmark, not a reason to go looking.

> 🔴 **Do not contact the other reader**, and do not ask anyone to relay what they are doing.
> Two independent readings are the experiment.

Your work commits go to this surface's own git repository, on its own branch, at milestone
granularity. Nothing here writes to any LEGEND canonical file.
